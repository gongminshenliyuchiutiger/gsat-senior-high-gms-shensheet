# 單元 7　法治的建構與意涵（法律篇）

## 重點 1｜社會規範與社會變遷

### 一、社會規範的概念與功能

| 項目 | 內涵說明 |
| :--- | :--- |
| **意義** | 基於社會共同生活的需要，人們在社會互動過程中，衍生出社會成員認可或必須共同遵守的**行為準則**。 |
| **概念** | 1. **分化現象**：為符合不同群體需要，由原始社會的「神諭與禁忌」，逐漸分化為現代社會的「**習俗、宗教、道德、法律**」。<br>2. **相對性**：社會規範會因不同的社會而有異，也會因情境的不同而有別。 |
| **功能** | 1. **維持社會秩序**：人際關係錯綜複雜、互動頻繁，必須建立共同遵守的規範，紛爭才能解決，秩序才能維持。<br>2. **形成社會控制**：<br>　* **內在控制**：將社會規範內化於心，成為人格的一部分。若行為不符規範，內心將感到羞愧或不安（例：搭大眾運輸未讓座給老弱婦孺）。<br>　* **外在控制（正式）**：透過具**強制力**的法律，由執法人員依法約束與管理人民行為（例：闖紅燈處以罰鍰）。<br>　* **外在控制（非正式）**：以道德習俗或同儕團體作為評斷或訂定獎懲機制，產生約束作用（例：排隊不爭先恐後）。 |
| **影響與變遷** | 1. **反映主流期待**：社會規範反映主流群體的想法，可能影響個人的自我實現（例：職業的性別區隔、過去政府對原住民族土地的政策）。<br>2. **隨時代動態調整**：價值觀念並非一成不變（例：女性繼承財產比例提升、廟宇減香環保概念、提高未禮讓行人罰鍰）。 |

## 重點 2｜民主法治國家的法律制定

### 一、民主國原則與法治國原則

```
【民主國原則】
  人民 ──(定期改選/多數決)──► 民意代表 ──(制定法規)──► 法律（具備民主正當性）
  
【法治國原則】
  法律 ──(至高無上的規範約束)──┬─► 人民：依法行使權利、負擔義務
                                └─► 政府 ─┬─ 立法機關：依法立法
                                          ├─ 行政機關：依法行政
                                          └─ 司法機關：依法審判
```

* **民主國原則**：國家統治的正當性來自於**人民**（韋伯觀點：統治者具民意基礎）。人民透過參與、決定國家政治意志，選出代表機關及元首，使法律具備**民主正當性**。具體內涵包括：國民主權、定期改選、政黨政治、多數決原則（《憲法》第 2 條）。
* **法治國原則**：指**人民和政府都必須遵守法律的規定**。國家權力的行使：立法機關依法定程序制憲與修法；行政機關依法行政；司法機關依法獨立審判。具體內涵包括：保障人權、權力分立、依法行政、司法獨立、權利救濟途徑。

---

### 二、法律須經民主正當程序制定與修改（立法院通過、總統公布）

#### 1. 提案階段
* **政府提案**：行政院、司法院、考試院、監察院僅就其職權範圍得向立法院提出法律案，不得侵犯其他院所轄之事務。
* **立委提案**：由 **15 人以上** 立法委員之連署，或符合《立法院組織法》規定之**黨團**提出。  
  *(註：人民無直接提案權，但可透過請願、陳情、遊說等方式促成修法)*

#### 2. 編列議程
* 提案先送**程序委員會**（委員 19 人，按政黨席次比例分配）審定提案程序是否完備，並決定院會審議法案的優先次序。

#### 3. 三讀程序
```
【一讀會】（宣讀標題）
  院會時由主席宣讀標題 ──► 交付相關常設委員會審查（或逕付二讀）
         │
         ▼
【委員會審查與黨團協商】
  立法院設有 8 個常設委員會與 4 個特種委員會進行實質審查與條文協商
         │
         ▼
【二讀會】（實質審查核心）
  朗讀議案 ──► 廣泛討論 ──► 逐條討論 ──► 修正及表決（或重付審查、撤銷）
         │
         ▼
【三讀會】（形式文字把關）
  原則上只進行「文字修正」，不修改實質內容（除非發現條文互相牴觸或違憲）
         │
         ▼
【表決議決】
  須全體立委 1/3 以上出席，出席委員 1/2 以上同意始為通過
```

#### 4. 公布與施行
* **總統公布**：立法院完成三讀之法律案，咨請總統於收到後 **10 日內公布**，並經行政院院長及有關部會首長**副署**。一般法案自總統公布之日起算至**第 3 日起生效**。
* **行政院覆議程序**：
  * 行政院若認為法律案**窒礙難行**，經**總統核可**後，於送達行政院 **10 日內** 移請立法院覆議。
  * 立法院應於送達 **15 日內** 作成決議：
    * 全體立委 **1/2 以上決議維持原案** $\rightarrow$ 行政院長必須接受，法案**正式施行**。
    * 未達 1/2 維持原案（不維持原決議）或逾期未作成決議 $\rightarrow$ 原決議失效。

## 重點 3｜法律的解釋、適用與層級

### 一、法律解釋的方法

#### 1. 依解釋主體區分
* **有權解釋（機關解釋，具拘束力）**：
  1. **立法解釋**：立法者率先在法條文字中對重要名詞做出定義（例：刑法第 10 條對「公務員」、「性交」之定義）。
  2. **行政解釋**：行政機關根據職權與專業，就相關法律發布函釋，方便基層執行與人民理解。
  3. **司法解釋**：法官依憲法與法律獨立審判，於裁判中表示自認合法適當的理由；或憲法法庭大法官作成之裁判解釋。
* **無權解釋（學理解釋，無拘束力）**：
  * 人民、法學學者、媒體輿論對法律條文的學術研究與論述說明，供實務裁判參考，但無實質法律約束力。

#### 2. 依解釋方法區分
* **文義解釋（文理解釋）**：直接依法律條文的**字面文義**判斷其意涵，是**最直接、最常用**的方法（如罪刑法定主義嚴格遵守文義）。
* **歷史解釋（沿革解釋）**：依據制定或修改法律時的**時空背景、歷史資料與立法紀錄**，判定當初立法者的真意。
* **體系解釋（系統解釋）**：除法條本身外，**參考其他相關法條或整體法規範系統的關聯**來解釋意旨（例：對照《消費者保護法》與《民法》之連帶責任）。
* **目的解釋**：依據該項法規或條文所欲達成的**立法目的與宗旨**來判斷其意涵。

---

### 二、法律解釋與適用的基本原則

| 原則名稱 | 核心內涵與說明 | 具體要求與範例 |
| :--- | :--- | :--- |
| **符合法治國原則** | 解釋法律必須考量**法律的位階與合憲性**問題。 | 法律解釋不可牴觸憲法意旨；法律解釋不可與文義相悖；相同法律解釋應前後一致，維護社會對法律之信賴。 |
| **誠實信用原則** | 無論是私人之間的交易或人民與國家間的法律行為，均應以誠實、守信方法為之。 | 不得欺瞞、趁人之危或以其他悖於道德誠信的方式行使權利或履行義務。 |
| **禁止權利濫用原則** | 不得任意擴大有關自己權利的法律解釋，而損害他人或公共利益。 | 行使個人權利若造成公共利益或他人權益的重大損害，國家法律應予禁止。 |
| **特別法優先於普通法** | 以法律**效力所及範圍與對象**區分。當普通法與特別法對同一事項皆有規範時，優先適用特別法。 | 特別法適用於特定人、事、時、地、物（如《陸海空軍刑法》優先於《刑法》；《公司法》優先於《民法》）。 |
| **程序法先於實體法** | 以法律**規範內容性質**區分。司法機關應先依程序法確認是否合法受理，再依實體法做出實質判決。 | 先審查提告管轄、時效與程序（程序法），再審究實質權利義務與法律效果（實體法）。 |

---

### 三、法律適用的邏輯：司法三段論法

```
【大前提】法律規範 ──► 例如：《刑法》第 309 條規定：「公然侮辱人者，處拘役或 9,000 元以下罰金。」
   │
   ▼
【小前提】案件事實 ──► 例如：小華對小明心生不滿，在小明的臉書公開貼文大罵「無恥、智障」。
   │                  （公開貼文符號「公然」，侮辱字眼符號「侮辱」）
   ▼
【結  論】法律效果 ──► 小華的行為構成公然侮辱罪，依法判處罰金 9,000 元。
```

### 延伸補充：凱爾森「法律層級構造理論」

```
           ▲
          / \        【憲法】
         /   \       最高性、原則性規範，修改最困難。
        / 法律 \      【法律】
       /────────\     法、律、條例、通則。不得牴觸憲法。
      /  行政命令 \   【行政命令】
     /────────────\  規程、規則、細則、辦法、綱要、標準、準則。不得牴觸憲法與法律。
    / 行政處分、裁判 \【個別規範】
   /────────────────\ 行政處分、法院判決。直接針對具體個案，具體適用。
```
* **上位階規範指導下位階規範**：下位階規範不得牴觸上位階規範。
* **特性比較**：層級愈高，效力愈高、數量愈少、規範愈抽象、修改愈困難；層級愈低，規範愈具體、數量愈多、修改較容易、個案優先適用。

### 延伸補充：法律的各類分類方式

| 區分依據 | 法律類別 | 定義與實例 |
| :--- | :--- | :--- |
| **規範對象** | **公法** | 規範國家與人民間之公權力關係（如《憲法》、《刑法》、《行政法》）。 |
|  | **私法** | 規範平等私人間之財產與身分關係（如《民法》、《公司法》）。 |
|  | **公私混合法（社會法）** | 兼具私法自治與國家公權力介入扶助（如《勞動基準法》、《消費者保護法》、《家庭暴力防治法》）。 |
| **規範性質** | **實體法** | 規定權利與義務之實質內容（如《民法》、《刑法》）。 |
|  | **程序法** | 規範實現權利、義務及尋求法律救濟之程序（如《民事訴訟法》、《刑事訴訟法》、《行政訴訟法》）。 |
| **適用範圍** | **普通法** | 適用於一般人、事、時、地（如《民法》、《刑法》）。 |
|  | **特別法** | 適用於特定人、事、時、地，優先適用（如《公司法》、《陸海空軍刑法》、《貪污治罪條例》）。 |
| **法律形式** | **成文法（制定法）** | 經立法機關通過並公布之文字法規（大陸法系國家為主，如臺、德、法）。 |
|  | **不成文法** | 判例、習慣法、法理等（英美法系國家為主，如英、美）。 |

## 重點 4｜人民及政府被賦予法律上的義務

### 一、人民在我國須承擔的憲法義務

* **民主正當性來源**：要讓人民承擔法律義務，必須獲得人民的同意。人民透過選舉制度選出民意代表，民代匯集民意、討論並制定出多數人都能認同、接受與遵守的法律規則。
* **我國憲法明定的三大基本義務**：
  1. **《憲法》第 19 條**：人民有依法律**納稅**之義務。
  2. **《憲法》第 20 條**：人民有依法律**服兵役**之義務。
  3. **《憲法》第 21 條**：人民有受**國民教育**之權利與義務（兼具權利與義務雙重性）。
* **人民承擔義務之限制**：要求人民負擔義務也是對人民自由權利的限制，必須符合**《憲法》第 23 條之法律保留原則與比例原則**，限於「防止妨礙他人自由、避免緊急危難、維持社會秩序、增進公共利益」所必要者，始得以法律限制之。

---

### 二、高中校園中的民主與學生的權利義務

* **學生自治的法源**：
  * 《高級中等教育法》第 53 條：高級中等學校應輔導學生成立全校學生選舉產生之**學生會**及其他相關自治組織，並提供必要協助，以增進學生在校學習效果及自治能力。
* **學生自治的正當程序**：全校學生選舉學生代表的過程，必須符合民主選舉之普遍、平等、直接、無記名原則。
* **校園重大決策與學生代表參與**：
  * 過去學校偏重管理支配，現今強調透過民主參與學習負責。
  * 依《高級中等教育法》規定，攸關學生權益之會議（如第 25 條**校務會議**、第 52 條**學生獎懲委員會**），均應有**學生代表參與**，落實學生表意權與校園民主實踐。

* **資料二**：《兵役法》第 1 條規定：「中華民國男子依法皆有服兵役之義務。」

* **資料四**：《兵役法》第 3 條規定：「男子年滿 18 歲之翌年 1 月 1 日起役，至屆滿 36 歲之年 12 月 31 日除役，稱為役齡男子。」
* **資料五**：《兵役法》第 4 條及第 5 條有「免役」與「禁役」之規定。2000 年時任總統陳水扁曾提出「募兵為主、徵兵為輔」兵役政策；2011 年至 2013 年時任總統馬英九執政期間，透過《志願士兵服役條例》與《兵役法》修正案，確立了「<u>志願役為主、義務役為輔</u>」的兵役政策，並透過行政命令，將兵役縮減為 4 個月。但近年來，隨著中共軍機屢次越過臺灣海峽，侵擾臺灣空域，不僅影響臺灣安全，也引發國際社會關切。經相關部會協調定案，2022 年時任總統蔡英文正式宣布，2005 年 1 月 1 日出生之役男，自 2024 年 1 月 1 日起，兵役將從 4 個月正式延長為 1 年。屆時義務役士兵每月薪資調升為 26,307 元，接近基本工資。新制實施後，首批徵集 9,127 名役男，以鄰近戶籍地為原則。

> * **資料四**：《兵役法》第 3 條規定：「男子年滿 18 歲之翌年 1 月 1 日起役，至屆滿 36 歲之年 12 月 31 日除役，稱為役齡男子。」

1. 根據以上的資料，請判斷下列何者正確？  
> (A) 臺灣服役的年齡為 18 歲至 36 歲，所有的男性皆須服兵役  
> (B) 陳水扁任內確立「志願役為主、義務役為輔」的兵役政策  
> (C) 我國兵役時間的縮短甚或延長，乃是經由立法院三讀通過  
> (D) 相關法律與政策的更迭，會隨著社會時代變遷而有所改變  
> 
> **【參考答案】(D)**  
> *解析：(A) 兵役法有免役與禁役規定；(B) 馬英九任內確立志願役為主；(C) 役期長短依兵役法授權由行政院核定公告；(D) 兵役制度與國防安全、人口與國際局勢息息相關，隨時代變遷而動態調整。*

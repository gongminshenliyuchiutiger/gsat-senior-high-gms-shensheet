# 單元 12　契約自由與勞動權益保障（法律篇）

---

## 重點 1｜契約自由與合理的限制

### 一、契約自由：基於私法自治的原則

* **定義**：締結契約與否之自由、相對人選擇自由、契約內容自由、締約方式自由、廢棄或變更契約自由。
* **核心理由**：
  1. 對個人意志的尊重，並防止國家法律對個人日常社會生活關係的不當干預。
  2. 使當事人能自由交換財貨或勞務，有助於社會資源有效率的配置。
  3. 保護契約當事人相互的信賴，維護交易安全，並符合道德規範。

---

### 二、契約的基本原則與限制

```
契約基本原則與限制
 ├─ 誠實信用原則 ── 內容顯失公平或行使權利違背誠信者無效
 ├─ 契約的社會化 ── 基於社會福祉與公共利益，國家公權力適度介入契約自由（憲法第 23 條）
 ├─ 締約自由限制 ── 強制締約（民生必需或急難救助，占優勢之一方不得無故拒絕締約）
 ├─ 方式自由限制 ── 要式契約（特定契約依法須以「書面」為之，如婚姻、不動產移轉）
 └─ 其他實體限制 ── 不得違反法律強制／禁止規定、不得違背公序良俗、不得顯失公平
```

| 限制面向 | 核心意涵 | 具體規範與實例 |
| :--- | :--- | :--- |
| **誠實信用原則** | 若發生不當情事，誠信原則介入調整雙方之權利義務：<br>1. 契約內容明顯偏袒一方，違反平等互惠原則，**顯失公平者 $\rightarrow$ 無效**。<br>2. 當事人使用違反誠實及信用之方法行使權利或履行義務 $\rightarrow$ **無效**。 | 雇主於勞動契約中片面約定「懷孕即自動離職」，顯失公平且違反誠信原則，該條款無效。 |
| **契約的社會化** | 1. 國家基於社會福祉以公權力干涉契約自由，抑制契約自由之流弊（維護**契約正義**）。<br>2. 契約自由受法律規範與保護，但若內容不符社會正義，則為法律所不許（憲法第 23 條公益限制）。 | 我國制定《消費者保護法》、《勞動基準法》以公權力介入私法契約，保護經濟弱勢方。 |
| **締約自由的限制<br>（強制締約）** | 民生必需或急難救助事項，**占有優勢的一方無正當理由，不得拒絕成立契約**。 | 醫院診所不得無故拒絕急救病患（緊急醫療服務）；自來水公司、電力公司、電信公司無正當理由不得拒絕供水、供電及提供通信服務。 |
| **方式自由的限制<br>（要式性）** | 契約成立原則上不拘形式（口頭、跑馬燈、廣告均可成立）；但在特定重大法律行為，法律規定**必須以書面為之（要式契約）**。 | 結婚與兩願離婚登記（須書面並有證人）、不動產物權移轉或設定（須書面並登記）、保險契約、分期付款買賣契約等。 |
| **其他法定限制** | 1. **違反法律強制或禁止規定者無效**。<br>2. **違背公共秩序或善良風俗（公序良俗）者無效**。<br>3. **顯失公平之定型化條款無效**。 | 買賣毒品、槍械之契約無效；賣身契、約定放高利貸（重利）無效；企業制定免除自身故意重大過失責任之定型化條款無效。 |

## 重點 2｜消費者權益的保障

### 一、法源：《消費者保護法》
* **立法目的**：促進國民消費生活安全、提升國民消費生活品質、規範企業經營者的義務和消費者的權益，同時帶動企業良性發展。

---

### 二、核心消費保護制度

#### 1. 定型化契約
* **定義**：由企業經營者**單方預先擬定**好條款內容，提供**不特定多數人**簽訂的契約（包含書面、放映字幕、張貼、牌示、網頁等）。
* **有效成立條件**：
  1. **平等互惠原則**：定型化契約條款如有疑義時，應為**有利於消費者**之解釋。
  2. **誠實信用原則**：條款違反誠信原則，對消費者顯失公平者，**無效**。
  3. **合理審閱期間**：企業應提供消費者 **30 日以內**之合理審閱期間，以審閱全部條款內容。若條款因字體過小或印刷等原因致難以注意或辨識者，該條款不構成契約內容。

#### 2. 特種交易與 7 日猶豫期（鑑賞期）

| 特種交易類型 | 定義與交易型態 | 猶豫期（鑑賞期）規範 |
| :--- | :--- | :--- |
| **通訊交易** | 以電視、電話、網際網路等方式，消費者**無法當場檢視商品或服務**之情況下，與企業訂立之契約。 | 1. 消費者於收到商品或接受服務後 **7 日內**，得**不附任何理由與負擔任何費用**，以書面通知或退回商品方式**解除契約**。<br>2. 企業須告知是否適用猶豫期及退換貨管道。<br>3. 若消保法無特別規定，仍適用民法「**出賣人負瑕疵擔保責任**」。 |
| **訪問交易** | 企業經營者**未經邀約**而在消費者的居所、工作場所、公共場所或其他場所（如路邊推銷）所訂立之契約。 |
| **分期付款** | 買賣契約約定消費者先支付頭期款，餘款分期支付，企業交付標的物之交易型態。**必須以書面為之**。 |

---

### 延伸補充：不適用 7 日鑑賞期的法定合理例外商品（通訊交易解除權合理例外情事準則）
1. **易腐敗、保存期限較短**，或退貨時即將逾期（如：鮮奶、生鮮蛋糕、現做餐點）。
2. **客製化給付商品**（如：刻印姓名之印章、量身訂做西服）。
3. **報紙、期刊或雜誌**（具強烈時效性）。
4. **經消費者拆封之影音商品或電腦軟體**（易於被重製抄錄）。
5. **非以有形媒介提供之數位內容或一經提供即為完成之線上服務**（如：電子書、購買付費軟體點數、線上串流），經消費者事先同意始提供。
6. **已拆封之個人衛生用品**（如：內衣褲、刮鬍刀、牙刷）。
7. **國際航空客運服務**（機票訂購）。

---

### 延伸補充：《消費者保護法》 vs. 《公平交易法》

| 比較項目 | 《消費者保護法》（消保法） | 《公平交易法》（公交法） |
| :--- | :--- | :--- |
| **主管機關** | 行政院消費者保護會、各地方政府消保官 | 獨立機關：**公平交易委員會** |
| **規範目的** | 保護消費者權益、促進國民消費生活安全、提升消費生活品質、規範企業義務。 | 維護交易秩序、保護消費者利益、**確保事業公平競爭**、促進經濟安定與繁榮。 |
| **核心規範內容**| 1. 定型化契約規制<br>2. 特種交易（通訊、訪問交易）<br>3. 消費資訊揭露與定型化契約應記載／不得記載事項<br>4. 消費爭議調解與消費訴訟 | 1. 獨占事業濫用防制<br>2. 限制競爭行為（如：禁止事業聯合壟斷、杯葛限制）<br>3. 不公平競爭行為（如：**虛偽不實之廣告**、營業誹謗、營業秘密侵害） |

> ### <i class="fa-solid fa-pen-to-square"></i> 公民神演練！
> 我國房屋市場的「預售屋」是指尚未開始動工或正在施工，而預先銷售的房屋。有的建商在預售屋銷售時，打出不實廣告，藉此促銷，例如：有建商在廣告文宣中呈現「空中景觀泳池」的意象，但實為無景觀之一般泳池；另外，也有建商為營造購屋熱潮，形成預期心理，哄抬建案價格，喊出「本案即將完銷」，但實際上該建案還有多戶未售出。也有投資客看準購屋者的預期心理，搶先簽訂預售屋買賣契約，俗稱紅單，而後換約轉售紅單，進行預售屋炒作，政府因而修改相關法律條文，規定預售屋買賣契約禁止讓與或轉售。針對題文中建商的行為，下列論點何者合乎我國現行《民法》與相關法規？【112. 分科】  
> (A) 若無脅迫他人買賣房屋，政府基於契約自由無法介入  
> (B) 政府可透過消保法或公平交易法管制建商的泳池廣告  
> (C) 刊登廣告係為勸說消費者購買，內容雖誇大並不違法  
> (D) 泳池廣告不屬契約的一部分，依法不得拘束買賣雙方  
> 
> **【參考答案】(B)**  
> *解析：(A) 契約自由受法令限制（契約社會化），政府基於公益得立法管制不當炒作行為；(B) 正確，建商刊登虛偽不實或引人錯誤之廣告，違反《公平交易法》第 21 條，且依《消費者保護法》第 22 條規定企業經營者應確保廣告內容之真實，建商所負之義務不得低於廣告之內容，政府機關均得依法查處；(C) 不實廣告已違反法規，並非單純誇大不違法；(D) 依消保法規定，廣告內容即構成契約內容之一部分，對建商具法律拘束力。*

## 重點 3｜個別勞動權益與集體勞動權益的保障

### 一、市場性勞動與家務勞動的差異

| 比較面向 | 市場性勞動（就業市場） | 家務勞動（再生產勞動） |
| :--- | :--- | :--- |
| **所屬領域** | **公領域**：人們付出勞務以交換工資或薪酬回報。 | **私領域**：付出勞務以維持家庭生活品質、照護老幼與家庭事務。 |
| **經濟價值** | **具有市場交換價值**。 | **不具有市場交換價值**（無市場交易價格）。 |
| **與 GDP 之關係**| 領取工資報酬，**計入國內生產毛額（GDP／國民所得）**。 | 無實質給付工資，**不計入 GDP**。 |
| **雙方互補性** | 1. 家務勞動使外聘勞動者無後顧之憂專心投入生產，提升職場工作效率。<br>2. 勞動者返家後能獲得妥善的身心照護與精力恢復。<br>3. 兩者共同促成整體社會與國家的永續經濟發展。 |
| **現實難題** | 無論男性或女性，從事家務勞動者常面臨「家庭與工作兩頭燒」的雙重負擔，甚至被迫退出職場中斷職涯。 |

---

### 二、保障勞動契約的緣由與方式

* **現實問題（勞資地位實質不對等）**：
  1. 雇主掌握聘僱、解僱、考績核定及降職升遷等權力。
  2. 雇主通常對國家法規與政策較為熟稔，在社會與經濟地位上占據絕對優勢。
  3. 受僱者常因欠缺法律知識或身處經濟經濟弱勢，半自願、半強迫地簽下不利且不合理的勞動契約。
* **保障方式（國家公權力積極介入）**：
  * 透過國家立法（如《勞動基準法》）設定最低勞動條件（工資底線、最高工時、加班費率），禁止雇主恣意壓榨。
* **臺灣勞動環境之挑戰與因應**：
  * **非典型僱用增加**：勞動市場朝彈性化發展，派遣工、臨時工、部分工時、外包承攬大幅增加。
  * **勞動檢查制度**：為保障勞工權益，中央設勞動檢查機構，勞工發現雇主違法可檢舉申訴，勞檢員得逕赴工作場所實施專案或例行檢查。

---

### 三、勞動權益的體系劃分

```
勞動權益保障
 ├─ 個別勞動權 ───────《勞動基準法》（工資、工時、休假、職災等法定最低條件）
 └─ 集體勞動權（勞動三權）
      ├─ 團結權 ──────《工會法》（組織及加入工會）
      ├─ 集體協商權 ───《團體協約法》（工會代表與雇主簽訂團體協約）
      └─ 爭議權 ───────《勞資爭議處理法》（行使合法抗爭與罷工）
```

---

### 四、個別勞動權：《勞動基準法》核心規範

* **立法目的**：規定**勞動條件的最低標準**，保障勞工權益、加強勞雇關係、促進社會與經濟發展。
* **重要法定基準**：
  1. **法定工時**：勞工每日正常工作時間不得超過 **8 小時**，每週工作總時數不得超過 **40 小時**。
  2. **休息時間**：勞工繼續工作 4 小時，至少應有 **30 分鐘**之休息。
  3. **一例一休**：勞工每 7 日中應有 2 日之休息，其中 1 日為**例假日**（不得出勤，天災事變除外），1 日為**休息日**（出勤須加成發給高額加班費）。
  4. **法律扶助救濟**：地方縣市政府勞工主管機關設有勞工權益基金，提供訴訟代理與涉訟法律救助。

---

### 五、集體勞動權：勞動三權與勞動三法

```
【工會組織】──────► 【集體協商】──────► 【合法抗爭】
   團結權                集體協商權              爭議權
  《工會法》            《團體協約法》        《勞資爭議處理法》
勞工有組織與加入工會    由工會代表全體勞工    調解不成立時，工會會員
之權利，形成談判力量    與雇主簽訂「團體協約」  無記名投票過半數可合法罷工
```

| 勞動三權 | 對應勞動三法 | 核心法律內涵與運作規定 |
| :--- | :--- | :--- |
| **團結權**<br>*(組工會)* | **《工會法》** | 1. 勞工有自願組織及加入工會的權利，以團體力量對抗資方優勢。<br>2. 雇主不得因勞工加入工會而予以解僱、降調等不當勞動行為。 |
| **集體協商權**<br>*(團體交涉)* | **《團體協約法》** | 1. 雇主無正當理由不得拒絕與工會協商。<br>2. 工會可就工資、工時、資遣等勞動條件與雇主談判並簽訂「**團體協約**」。<br>3. 團體協約效力高於個別勞動契約；**勞資會議**亦為法定自主協商預防爭議之平臺。 |
| **爭議權**<br>*(罷工權)* | **《勞資爭議處理法》** | 1. 勞資協商破裂並經調解不成立後，工會得發動合法爭議行為。<br>2. **合法罷工要件**：須經工會全體會員以**直接、無記名投票，且經全體過半數同意**，方得宣告罷工。<br>3. 合法罷工享有民事及刑事免責權，雇主不得以此請求損害賠償或予以解僱。 |

---

### 六、國際對勞動權之倡議與保障

* **國際勞工組織（ILO）**：倡導「**尊嚴勞動（Decent Work）**」，主張勞工應獲得一個尊重勞動者權益及提供基本社會安全保護的工作，協調政府、雇主與勞工三方利益。
* **聯合國永續發展目標（SDGs）**：SDG 8「促進包容且永續的經濟成長，達到全面且具生產力的就業，讓每個人都有一份尊嚴工作」，致力打造友善的勞動環境，實現公平正義。

> ### <i class="fa-solid fa-pen-to-square"></i> 公民神演練！
> 我國自從 1984 年實施《勞動基準法》以來，至今已有三十餘年的歷史。關於我國《勞動基準法》的敘述，下列何者最為正確？【106. 指考】  
> (A) 立意在維護雇主的權益，確保勞動市場穩定與提供勞動機會  
> (B) 透過勞動條件的最高標準規定，以保障受僱者的權益與福利  
> (C) 明確規定勞資雙方的權利與義務，用以做為解決糾紛的依據  
> (D) 明訂受僱者必要時可組織工會或舉行罷工，以爭取勞工權利  
> 
> **【參考答案】(C)**  
> *解析：(A) 立法主旨在於維護「勞工」基本權益，加強勞雇關係；(B) 勞基法規定的是勞動條件的「最低標準」，而非最高標準；(C) 正確，勞基法明訂了工時、工資、休假、資遣、退休等勞雇雙方法定權利與義務，作為規範勞動契約與處理爭端之基準；(D) 組織工會規範於《工會法》，罷工要件規範於《勞資爭議處理法》，非勞基法之規範範疇。*

| 法規名稱 | 核心立法目的與保障內容 |
| :--- | :--- |
| **《就業服務法》** | 保障國民就業機會平等（禁止年齡、性別、黨派、外貌、出生地歧視），促進國民就業，規範外籍移工引進與聘僱管理。 |
| **《就業保險法》** | 提升勞工職業技能，保障非自願離職勞工在失業一定期間內之基本生活（發給**失業給付、提早就業獎助津貼、職訓生活津貼**）。 |
| **《性別平等工作法》** | 消除職場性別歧視、促進性別地位實質平等。保障同工同酬、產檢假、生理假、育嬰留職停薪及家庭照顧假，防制職場性騷擾。 |
| **《勞工保險條例》** | 透過強制社會保險機制，保障勞工生活。給付涵蓋：生育、傷病、失能、老年、死亡給付，以及職業災害補償。 |
| **《勞動事件法》** | 於各級法院設立專業「**勞動法庭**」，引進勞動調解程序，以「迅速、妥適、專業、有效、平等」處理各類勞動紛爭。 |
| **《職業安全衛生法》** | 防止職業災害，保障工作者安全與健康。雇主對於機械設備危害、化學物質暴露及職場暴力，應採取法定必要預防設施與措施。 |

# 單元 8　憲法與人權保障（法律篇）

---

## 重點 1｜憲法對於人權保障的理念與內容

### 一、從人性尊嚴維護到基本人權保障

#### 1. 憲法保障的由來
* 隨著社會演進，人民的基本權利在種類與內涵上不斷擴充。
* 現代民主憲政國家中，法律必須同時兼具「**保障人民權利（Rights）**」與「**限制政府權力（Power）**」的作用。

#### 2. 憲法保障對象的層次區別

```
  ┌──────────────────────────────────────────────────────────┐
  │ 人權（普世權利）：身為「人」即具備的權利（如：平等、自由權） │
  │   ┌──────────────────────────────────────────────────┐   │
  │   │ 國民權：具備「國籍」才擁有的權利                    │   │
  │   │        （如：工作權、受教育基本權，涉及資源分配）     │   │
  │   │   ┌──────────────────────────────────────────┐   │   │
  │   │   │ 公民權：具備「公民」身分才享有的權利        │   │   │
  │   │   │        （如：參政權，涉及國家決策與基本認同）│   │   │
  │   │   └──────────────────────────────────────────┘   │   │
  │   └──────────────────────────────────────────────────┘   │
  └──────────────────────────────────────────────────────────┘
```

#### 3. 憲法規範方式
* **列舉基本權**：我國《憲法》第二章「人民之權利義務」（第 7～21 條），明文列出平等權、自由權、受益權、參政權。《憲法增修條文》第 10 條進一步針對性別實質平等、身心障礙者保障、原住民族語言文化與政治地位等加以補充。
* **概括基本權**：《憲法》第 22 條設有概括條款，規定「凡人民之其他自由及權利，不妨害社會秩序公共利益者，均受憲法之保障」。舉凡隱私權、姓名權、婚姻自由、契約自由等，皆受憲法保障。

---

### 二、我國憲法中的列舉基本權利

#### 1. 自由權（消極防禦權）
* **意義**：人民抵禦國家干預、防止國家公權力不當限制的消極防禦權。
* **主要內涵**：人身自由、居住遷徙自由、表現自由、秘密通訊自由、信仰宗教自由、集會結社自由。
* **重要性與釋憲實例**：
  * **人身自由（人身不可侵犯）**：
    * 是一切自由權的基礎，若遭剝奪將直接影響其他所有權利。
    * 《憲法》第 8 條規定，非經司法或警察機關依法定程序，不得逮捕拘禁。
    * **釋字第 392 號**：指出檢察官擁有羈押權與保障人身自由意旨不符，促使**羈押權回歸法院（法官保留）**。此外《刑事妥速審判法》將審判中累計羈押期間大幅縮減。
  * **意見自由（表現自由）**：
    * 《憲法》第 11 條保障言論、講學、著作及出版自由，為健全個人人格、監督國家施政之基石。
    * **憲法法庭 111 年憲判字第 2 號判決**：法院以判決命加害人「道歉」，侵害被告之不表意自由，違反憲法保障言論自由之意旨而違憲。

#### 2. 平等權
* **意義**：人民在法律上享有同等的權利，無分男女、宗教、種族、階級、黨派，在法律上一律平等（《憲法》第 7 條）。
* **重要原則**：
  * **禁止恣意差別對待**：大法官解釋強調「平等非機械式的絕對平等」，必須視實際情況之差異而有合理區隔。
  * **平等兩大層次**：
    * **形式平等（齊頭式平等）**：等者等之，不等者仍等之。先去除體制不平等。
    * **實質平等（立足點平等）**：等者等之，不等者不等之。針對特殊弱勢情形給予合理的「優惠性差別待遇」（積極平權措施）。

#### 3. 受益權（積極請求權）
* **意義**：人民可請求國家從事一定的作為，以享受特定利益之權利。
* **四大類型**：
  * **經濟上受益權**：
    * **生存權**：請求國家維持最低限度生活（如：低收入戶請領生活補助金）。
    * **工作權**：請求國家保障工作自由與協助就業（如：失業勞工職訓輔導）。
    * **財產權**：請求國家保障私有財產不受侵害（如：發明人申請專利權保護）。
  * **教育上受益權（受教權）**：人民享有接受國民教育及受教育補助的權利（《憲法》第 21 條，兼具權利與義務）。
  * **行政上受益權**：
    * **請願**：對國家政策、公共利益或個人權益事項，向行政機關陳述意見。
    * **訴願**：權利遭受行政機關違法或不當處分損害時，向其上級機關請求撤銷或變更。
  * **司法上受益權（訴訟權）**：人民權利受侵害時，得向法院提起訴訟請求公正審判；受國家公權力不法侵害時，可提國家賠償。

#### 4. 參政權
* **意義**：公民參與政治的權利，包含選舉、罷免、創制、複決，以及應考試、服公職之權。

### 三、其他概括基本權利（非憲法明文列舉，受《憲法》第 22 條保障）

| 權利名稱 | 核心重要性 | 相關大法官釋憲見解 |
| :--- | :--- | :--- |
| **隱私權** | 個人為確保人性尊嚴與個人自主發展，對其私密生活空間、個人資訊及重大決定之自主控制權。 | **釋字第 603 號**：戶籍法規定換發國民身分證須「按捺指紋」始得領取，侵害人民**資訊隱私權**，宣告違憲。 |
| **人格權** | 維護個人人格之完整性與不可侵犯性，體現在姓名權、名譽權、性自主權等面向。 | **釋字第 399 號**：以「姓名不雅不能以讀音會意擴大解釋」限制改名違憲，確立**姓名權**屬憲法保障之人格權。 |

### 延伸補充：請願、訴願與訴訟權之比較

| 權利類型 | 提出者 | 受理對象 | 提出的主要主張與目的 |
| :--- | :--- | :--- | :--- |
| **請願** | 任何人民 | 各政府機關、民意機關 | 對於國家政策、公共利益或個人權益維護事項，表達個人希望與意見。 |
| **訴願** | 權益遭受政府侵害之人民 | 原處分機關之上級**行政機關** | 主張政府某項行政處分**違法或不當**，致損害自身權益，請求撤銷或變更。 |
| **訴訟** | 權益受政府或他人侵害之人民 | 各級**司法機關（法院）** | 主張政府或他人侵害自身權益，請求法院依法進行裁判、賠償或追究處罰。 |

## 重點 2｜基本權利的合理限制

### 一、限制基本權的憲法規範（《憲法》第 23 條）

> 「以上各條列舉之自由權利，除為**防止妨礙他人自由**、**避免緊急危難**、**維持社會秩序**，或**增進公共利益**所必要者外，不得以法律限制之。」

```
《憲法》第 23 條核心要素
  ├─ 正當公益目的 ──┬─ 防止妨礙他人自由（如：二手菸防制）
  │                 ├─ 避免緊急危難（如：颱風預防性撤離安置）
  │                 ├─ 維持社會秩序（如：集會遊行秩序管制）
  │                 └─ 增進公共利益（如：興建公共工程依法徵收土地）
  ├─ 法律保留原則 ──── 限制人權須有立法院通過之「法律」依據（或明確法規命令授權）
  └─ 比例原則 ──────── 限制手段不得過當，須符合「適當性、必要性、衡量性」
```

---

### 二、依法限制個人自由及權利的兩大原則

#### 1. 法律保留原則（無法律依據，不得侵害人權）
* **意義**：若無法律授權做依據，國家不得恣意限制人民的基本權利。
* **法源**：《憲法》第 23 條中「以**法律**限制之」。
* **原則內涵**：要求公權力之行使受法律節制，特定重要事項保留由代表民意的立法機關制定；行政機關在無法律授權下不得主動限制人民權利，不能僅是消極不違法，更須**積極依法有據**。

#### 2. 比例原則（禁止過度原則）
* **意義**：公權力干預人權時，**不得「為達目的、不擇手段」**。有多種手段均可達成相同目的時，必須選擇對人民權益**侵害最小**的方式。
* **比例原則三大子原則與檢驗步驟**：
  1. **適當性原則（合目的性）**：採取之方法／手段必須**有助於**目的之達成。
  2. **必要性原則（最小侵害性）**：在所有能達成目的之手段中，應選擇**對人民侵害最小**之手段。
  3. **狹義比例性原則（衡量性原則）**：採行手段所造成之損害，與欲達成之目的利益**不得顯失均衡**。

---

### 比例原則檢驗範例：遏止酒駕政策之審查

> **案例情境**：政府為遏止酒精濃度達 0.15 mg/L 的酒駕行為，提出兩種政策方案進行衡量：
> * **方法 1**：全臺灣全面禁止賣酒。
> * **方法 2**：酒駕者處以有期徒刑並處行政處罰。

```
【第一步：適當性檢驗】手段是否有助於達成遏止酒駕之目的？
  ├─ 方法 1（禁止賣酒）：有效達成遏止酒駕 (<i class="fa-solid fa-check text-success"></i>)
  └─ 方法 2（徒刑與行政罰）：有效達成遏止酒駕 (<i class="fa-solid fa-check text-success"></i>)
          │
          ▼
【第二步：必要性檢驗】是否為所有能達成目的之手段中侵害最小者？
  ├─ 方法 1（禁止賣酒）：嚴重摧毀相關產業與人民日常，非最小侵害手段 (✘)
  └─ 方法 2（徒刑與行政罰）：針對違規者個別處罰，侵害較小 (<i class="fa-solid fa-check text-success"></i>)
          │
          ▼
【第三步：衡量性檢驗】手段所產生的侵害與公益是否顯失均衡？
  ├─ 方法 2 若一律課處「有期徒刑」：針對情節輕微者直接處重刑，手段利益失衡 (✘)
  └─ 方法 2 若改採「行政處罰」（吊扣駕照、罰鍰、移置車輛）：損益相當，合乎比例 (<i class="fa-solid fa-check text-success"></i>)

【結論】：依《道路交通管理處罰條例》施以行政處分符合比例原則。
```

## 重點 3｜憲法對結社自由的保障與限制

### 一、結社自由的定義與核心價值
* **定義**：指為達共同目的，依自由意志（志趣、信仰與理念）與他人組成正式或非正式的團體，並參與其活動之自由與權利。
* **重要性**：結社自由對民主政治健全發展有深遠影響。在司法審查標準上，除非具有**明顯而立即的危險**，否則國家應採取較為寬鬆彈性的規範，不應過度干涉人民結社。

---

### 二、結社自由與公益管制的權衡

1. **集體犯罪行為危害社會不受憲法保障**：
   * 《刑法》明文處罰「參與以犯罪為宗旨之結社」。
   * 若結社團體純以組織犯罪集團、侵害他人生命與財產安全為目的（如黑幫組織），自不受憲法結社自由之保障。
2. **規範公職人員須保持政治中立**：
   * 《憲法》及相關法律規定公職人員（如法官、大法官、考試委員、監察委員、現役軍人等），其政治行為應嚴守超然中立，超出黨派之外，避免影響國家公權力之公正運作。
3. **避免政黨活動危害民主憲政秩序**：
   * 《憲法增修條文》第 5 條規定，政黨之目的或其行為，若危害中華民國之存在或自由民主之憲政秩序者，主管機關得聲請**司法院憲法法庭判決解散**。

---

### 三、人民團體的法定組織程序
* 人民團體之組織，應由發起人（需成年）檢具申請書、章程草案及發起人名冊，向**主管機關（內政部或地方社會局處）申請許可**。
* 經主管機關核准立案後，團體得依法向地方法院登記處辦理**法人登記**，取得法人資格。

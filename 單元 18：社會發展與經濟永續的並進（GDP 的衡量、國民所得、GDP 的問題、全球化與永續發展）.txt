# 單元 18　社會發展與經濟永續的並進（經濟篇）

---

## 重點 1｜國民所得的衡量方式

### 一、國內生產毛額（GDP, Gross Domestic Product）

#### 1. 內涵與核心定義
* **定義**：指**一國的國內在一定期間內，所生產最終產品及服務的「市場價值總和」**。
* **名目 GDP vs. 實質 GDP**：
  * **名目 GDP（Nominal GDP）**：以**當年度的物價**為基準計算，忽略了物價波動的影響。
  * **實質 GDP（Real GDP）**：以**基期的物價**來計算，剔除物價膨脹因素，能精確還原該年度「實質生產力」的真實變動。

#### 2. GDP 的四大核心構成要素

| 要素項目 | 內涵說明與判斷標準 | 實例說明 |
| :--- | :--- | :--- |
| **一國國內<br>（屬地主義）** | 只計入**國境之內**生產的價值。將境內所有經濟主體（**不論本國人或外國人**）所生產之最終財貨與服務皆列入。 | 1. 美商好市多在臺灣分店的營收 $\rightarrow$ **計入我國 GDP**。<br>2. 鴻海公司在美國威斯康辛州設廠之產值 $\rightarrow$ **計入美國 GDP**。 |
| **一定期間** | 通常以**一季（Q）或一年（Y）**為衡量區間，反映當期流量總價值。 | 計算當期新生產的產值；二手商品轉賣不計入（仲介費除外）。 |
| **生產的最終財貨與服務** | **只計入最終產品價值**。若為生產過程中投入的原料、半成品（中間產品），其價值不應重複計入，以避免重複計算。 | 烘焙店購買麵粉揉製麵包，只計入「麵包（最終產品）」的售價，麵粉的價格不重複計算。 |
| **市場交易之總價值** | **只計算透過市場公開交易並具有市場價格的部分**。未在正式市場進行交易的活動皆不計入。 | 1. **不計入**：路邊未開發票蔥油餅（地下經濟／黑市）、二手品拍賣、家務勞動、自願志工服務。<br>2. **法定例外（計入）**：**自用住宅的設算租金**、**農家自給自足之農產品**（具客觀市場參考市價可估計）。 |

### 二、國內生產毛額（GDP）的衡量方法（三面等價原則）

```
                                  【產品市場】
                                 （產品與服務）
                                ╱              ╲
                    支出（支出面）            收入（生產面）
                            ╱                      ╲
                           ▼                        ▼
                       【家  戶】                  【廠  商】
                           │                        ▲
                           │                        │
                    要素供給│                        │要素成本
                    (所得面)▼                        │
                                ╲              ╱
                                  【要素市場】
                            (勞動/土地/資本/企業才能)

  ▲ 國民經濟循環圖：一國當年的總產值，可分別從「生產面」、「支出面」、「所得面」進行衡量，理論上三者數額相等。
```

---

### 三、三面衡量法的計算公式與要素

#### 1. 生產面（附加價值法）
* **計算公式**：
  $$\text{附加價值} = \text{銷貨收入} - \text{進貨原料成本}$$
* **意涵**：從最終財貨與服務的市場價值加總，即為所有產業創造之附加價值總和。
* *實例*：汽車製造廠於屏東工廠當年度組裝完成的汽車總市價，不論當年度是否順利售出，皆全數計入該年度 GDP。

#### 2. 支出面（總支出法）
* **計算公式**：
  $$\text{GDP} = C + I + G + (X - M)$$

```
GDP 支出面四大要素
 ├─ 民間消費支出 (C) ─── 家戶在市場上購買之耐久財、非耐久財與服務（占 GDP 比重最高）
 ├─ 國內投資支出 (I) ─── 民間企業廠房設備購置、存貨變動，以及政府之各項資本硬體建設
 ├─ 政府消費支出 (G) ─── 各級政府公務採購、軍公教薪資支出（社福移轉性支付「不計入」）
 └─ 淨出口 (X - M) ───── 本國出口總值 (X) 扣除進口總值 (M)（順差 > 0，逆差 < 0）
```

* **重要觀念**：
  * **政府移轉性支出不計入 GDP**：如失業救濟金、育兒津貼、老人年金、振興五倍券等，屬於所得重分配，**不涉及新生產活動，故不計入 GDP**。
  * **扣除進口（$-M$）**：因 $C$、$I$、$G$ 中已包含購買外國進口品的支出，為精確反映「國內自製」產值，必須扣除進口以避免虛增產值。
* *以臺灣 2016 年 GDP 結構為例（總計 15.8 兆元）*：
  $$C(55.7\%) + I(22.8\%) + G(14.5\%) + \text{淨出口}(X: 74\% - M: 67\%) = 100\%$$

#### 3. 所得面（要素報酬分配法）
* **要素報酬構成**：
  $$\text{國民所得 (NI)} = \text{工資（勞力）} + \text{地租（土地）} + \text{利息（資本）} + \text{利潤（企業才能）}$$
* **國民所得毛額（GNI, Gross National Income）**：
  * **界定依據**：採「**常住居民（屬人主義）**」原則。本國常住居民在「國內及國外」提供生產要素所獲取的所得總額。
  * **轉換公式**：
    $$\text{GNI} = \text{GDP} + \text{常住居民在國外要素所得} - \text{非常住居民在國內要素所得}$$
    $$\text{GNI} = \text{GDP} + \text{國外要素所得淨額}$$

---

### 延伸補充：GDP vs. GNI 核心差異比較

| 比較項目 | 國內生產毛額（GDP） | 國民所得毛額（GNI） |
| :--- | :--- | :--- |
| **界定核心** | **「屬地主義」**（以國境地理界線為準） | **「屬人主義」**（以本國常住居民身分為準） |
| **計算標準** | 只要在**本國境內**生產，不論本國人或外國人。 | 只要為**本國常住居民**所賺取，不論在國內或國外。 |
| **典型舉例** | • 台積電在臺廠房產值（<i class="fa-solid fa-check text-success"></i> 計入）<br>• 外籍移工在臺灣之薪資報酬（<i class="fa-solid fa-check text-success"></i> 計入）<br>• 臺灣工程師在美國領取的薪水（✘ 不計入） | • 臺積電在臺廠房產值（<i class="fa-solid fa-check text-success"></i> 計入）<br>• 臺灣派駐海外外交官之薪水（<i class="fa-solid fa-check text-success"></i> 計入）<br>• 外國歌星來臺快閃演唱會收益（✘ 不計入） |

### 延伸補充：國民所得（NI, National Income）之推展公式
$$\text{NI} = \text{GNI} - \text{固定資本消耗（折舊）} - \text{生產及進口稅淨額}$$
* 指本國常住居民從事生產活動後，實際扣除折舊與間接稅後所分得的「**要素報酬淨額**」。

> ### <i class="fa-solid fa-pen-to-square"></i> 公民神演練！
> 根據學者研究，荷蘭東印度公司與日本的進出口生意，於 1633 年後再度開張，並在 1638～1639 年達到高峰，成為日本最主要貿易夥伴之一。下圖為東印度公司與日本貿易興盛時期，販售所有商品及生絲的毛利潤（銷售收入－購買成本），其中生絲資料表示東印度公司賣生絲給日本所賺的錢。某生在估計 1638 年日本的 GDP 時，疏忽了題文與圖的相關貿易資料，經提醒納入後重新計算得到較高的 GDP 估計值。該生補上的必須是下列哪項資料才能得到這個結果？【112. 學測】  
> (A) 東印度公司該年度對日貿易的總收益高於總成本  
> (B) 東印度公司該年度對日貿易的總金額高於上年度  
> (C) 東印度公司販售商品給日本的金額低於向日本買入的金額  
> (D) 東印度公司賣生絲給日本的金額高於買入其他商品的金額  
> 
> **【參考答案】(C)**  
> *解析：*  
> * *依支出面公式：$\text{GDP} = C + I + G + (X - M)$。由日本的視角來看，$X$ 為日本向荷蘭出口的金額，$M$ 為日本向荷蘭進口購買的金額。*  
> * *題幹指出重新納入對荷貿易資料後「得到較高的日本 GDP 估計值」，意味著貿易差額 $(X - M) > 0$（即日本對荷貿易呈現**出超／順差**）。*  
> * *日本出超代表「日本對東印度公司的出口額 $(X)$ 大於進口額 $(M)$」，也就是「東印度公司向日本買入的金額 $(X)$ 高於販售給日本的金額 $(M)$」，亦即 (C) 所述「東印度公司販售商品給日本的金額低於向日本買入的金額」。*

## 重點 2｜經濟成長率與人民的生活水準衡量方式

### 一、經濟成長率（Economic Growth Rate）

* **定義**：透過實質 GDP 的相對變化，衡量一國在特定期間內實質生產動能的成長速度。
* **計算公式**：
  $$\text{經濟成長率 } (g) = \frac{\text{當期實質 GDP}_t - \text{前期實質 GDP}_{t-1}}{\text{前期實質 GDP}_{t-1}} \times 100\%$$

---

### 二、平均每人 GDP（Per Capita GDP）

* **定義與公式**：
  $$\text{平均每人 GDP} = \frac{\text{一國 GDP 總額}}{\text{該國總人口數}}$$
* **意涵**：剔除人口規模差異，代表該國平均每人的經濟生活水準，常用於國際間福祉與發展程度之評比。
* *我國近年平均每人 GDP 與經濟成長率對照*：
  * 2019 年：成長率 2.96%，人均 GDP 25,941 美元
  * 2020 年：成長率 2.98%，人均 GDP 28,383 美元
  * 2021 年：成長率 6.28%，人均 GDP 33,140 美元

---

### 三、GDP 數據的意義與局限性

#### 1. 數據意義
* 衡量總體經濟活絡程度的指標；GDP 成長通常帶動稅收、企業獲利增加與就業機會擴張。

#### 2. 指標局限性
* **無法反映所得分配不均**：人均 GDP 僅為平均數，若貧富差距極大，多數財富集中在少數富豪手中，人均數字無法展現基層大眾真實生活的困境。
* **無法衡量非市場生活品質**：忽略休閒價值、身心健康、犯罪率與民主自由等生活福祉。

---

### 四、綠色國民所得（Green GDP）

* **概念倡議**：聯合國為兼顧經濟成長與環境永續，主張應將生產過程中造成的「**自然資源耗損**」與「**環境品質劣化（污染損失）**」予以貨幣化估價，並從 GDP 中扣除。
* **計算公式**：
  $$\text{綠色國民所得} = \text{GDP} - \text{自然資源耗損} - \text{環境品質質損}$$

## 重點 3｜經濟指標的缺失與永續發展的挑戰

### 一、GDP 指標的五大缺失與偏差

```
GDP 指標評估偏差
 ├─【導致 GDP 被低估】
 │    ├─ 地下經濟難以計算 ─── 攤販、未開發票現金交易、黑市交易未納入申報
 │    ├─ 未計入非市場交易產值 ─ 家務勞動、長輩照顧、DIY 修繕等無償活動被排除
 │    ├─ 忽略休閒活動價值 ─── 犧牲休假長工時換取高產值，忽視過勞身心損害
 │    └─ 忽略產品與技術提升 ─ 科技進步使 3C 產品降價增質，產值數字無法反映享受升級
 └─【導致 GDP 被高估】
      └─ 未扣除經濟活動負產品 ─ 工廠排廢、水土流失等環境公害，社會成本未自 GDP 扣減
```

---

### 二、當代面臨的經濟永續難題

#### 1. 勞動力人口結構轉變
* **少子化危機**：出生率下降導致年輕工作人口短缺，未來可工作繳稅的青壯年不足，動搖國家經濟根基。
* **超高齡社會衝擊**：退休金與健保長照支出暴增，扶養比攀升，引發世代分配正義問題與嚴峻的政府財政赤字。

#### 2. 環境破壞 vs. 資源耗竭
* 地球資源有限，傳統高耗能、高污染的高速成長模式無法長期維繫；促使國家推動綠色能源轉型與循環經濟技術創新（人造資本代換自然資源）。

---

### 三、永續發展的概念與原則（Sustainable Development）

#### 1. 核心概念
* **布倫特蘭委員會正式定義**：
  > **「永續發展是指既能滿足當代人的需求，同時又不損及後代人滿足其本身需求的發展模式。」**

#### 2. 三大核心原則

| 原則項目 | 內涵說明 |
| :--- | :--- |
| **公平性原則** | 強調「**跨世代之間的公平**」（不透支後代生存資源），同時重視「**同一個世代內各階層與群體間的公平**」（消除貧窮與弱勢剝削）。 |
| **永續性原則** | 發展政策必須將**環境生態承受力、經濟繁榮、社會正義**三個面向兼籌並顧，不可偏廢。 |
| **共同性原則** | 各國雖發展程度與國情各異，但面對全球氣候變遷與公地悲劇，應採取**全球聯合行動**，共同承擔減碳責任。 |

---

### 四、全球化對國家治理的跨面向挑戰

* **經濟面**：
  * 全球通訊與航運大幅壓縮時空距離，各國經貿依存度極深。
  * *脆弱性*：單一地區的供應鏈中斷將引發全球連鎖反應（如：美國德州暴風雪導致晶圓廠停電，引發全球車用晶片大缺貨與價格暴漲）。
* **環境面**：
  * 開發中國家為吸引外資投資設廠，競相降低環保與排污標準，淪為跨國企業的「**污染避難所（污染天堂）**」，加劇全球溫室氣體排放與生態危機。
* **社會面**：
  * **先進國勞工結構性失業**：已開發國家製造業外移，導致本國傳統勞工面臨無薪假、派遣化、低薪與失業。
  * **跨國勞動剝削**：開發中國家勞動法規與工會不健全，跨國代工廠易演變為低薪、高工時、忽視工安的「**血汗工廠**」，擴大全球與國內貧富差距。

### 延伸補充：聯合國氣候變遷大會（COP 28）重要決議

* **歷史性突破**：近 200 個國家共同簽署決議，歷史上首次在峰會決議文中明確載明「**擺脫石化燃料（Transitioning away from fossil fuels）**」，推動能源轉型。
* **重要方針**：確立 2030 年全球再生能源裝置容量增加 3 倍、能源效率提升 1 倍；重申自 2023 年起**每 5 年進行一次全球盤點（Global Stocktake）**，檢視各國自主減碳進度並彈性調整氣候政策。

# 單元 16　市場失靈與因應對策（經濟篇）

---

## 重點 1｜為什麼會有市場失靈？

### 一、市場失靈的定義與成因

* **定義**：在自由經濟市場中，有時市場機能（價格機能／看不見的手）的運作失去作用，**無法使經濟資源有效利用、自動達成理想均衡**，導致此時經濟的**社會福祉並未達到極大化**。
* **市場失靈的四大成因**：
  1. **生產者之間缺乏競爭**（形成獨占、寡占）。
  2. **經濟行為產生外部效果**（外部成本、外部效益）。
  3. **公共財的性質與財產權的不完整**（共有財的悲劇、搭便車問題）。
  4. **資訊不對稱**（逆向選擇、檸檬車問題）。

---

### 二、市場失靈成因的意義與類型

#### 1. 獨占、寡占與聯合行為
* **意義**：某項產品或服務的生產者只有一個或少數幾個廠商，缺乏其他競爭對手，導致價格可以被特定廠商任意決定。

| 類型 | 內涵說明 | 實例說明 |
| :--- | :--- | :--- |
| **獨占** | 1. 只有一家廠商提供特定產品或服務（自然獨占：隨產量增加平均成本大幅下降，使小規模廠商被迫退出）。<br>2. 獨占原因亦可能是人為的（如法規特許、資本規模極大，進入門檻極高）。 | 自來水、電力供應、天然氣管線等公用事業。 |
| **寡占** | 提供特定產品或服務的生產者不只一個，但數量不多。廠商間相互競爭、牽制，但對市場價格具顯著影響力。 | 行動通訊電信業者（如三大電信）、石油煉製公司。 |
| **聯合行為<br>（卡特爾）** | 具競爭地位的廠商間，**私下協議共同制定價格策略、劃分市場或限制產量**，以避免價格競爭，實質上形同獨占。 | 幾大油廠或水泥業者協議同步漲價、限制出貨量以哄抬市價。 |

#### 2. 外部效果（外部性）
* **定義**：指個人消費或廠商生產的行為，**對交易雙方以外、無關的第三人產生正面（帶來好處）或負面（帶來損害）的影響**，且該影響無法反映在市場交易價格中（產生「外部不經濟」或「外部經濟」）。

```
外部效果類型
 ├─ 外部效益（正外部性）── 對第三人帶來好處，未獲回報 ──► 私人需求 < 社會需求 ──► 市場產量過少
 └─ 外部成本（負外部性）── 對第三人帶來損害，未付代價 ──► 私人成本 < 社會成本 ──► 市場產量過多
```

#### 3. 公共財（Public Goods）
* **定義**：指同時具有「**共享性（非敵對性）**」與「**無法排他性（非排他性）**」的產品或服務。
  * **共享性（非敵對性）**：一人享用該資源，不會減少其他人享用的數量或品質。
  * **無法排他性（非排他性）**：無法（或技術成本過高）阻止未付費的人享受該項利益。
* **市場失靈現象**：
  * 私人廠商難以向所有使用者收費，缺乏利潤誘因，**市場供給不足甚至無人願意提供**，通常須由**政府出資提供**（如國防、路燈、燈塔）。
  * 產生「**搭便車（Free-rider）心態**」：民眾想要坐享其成，不付出代價就享受成果（例如：佔用公共圖書館插座充私人電器）。

#### 4. 資訊不對稱（Information Asymmetry）
* **定義**：指買賣雙方在交易時所掌握的資訊量不同；擁有較多資訊的一方處於優勢，資訊較少的一方處於劣勢，無法在交易時做出最佳判斷。
* **市場失靈現象**：
  * 消費者因缺乏對商品品質、成本等完整判斷力，處於不公平或不利地位。
  * **檸檬車問題（Lemon Market）**：在二手車市場中，賣方比買方更清楚車況。因買方無法辨別好車或瑕疵車（檸檬），只願出平均價格，導致好車車主退出市場，最終市場充斥劣質品。

> ### <i class="fa-solid fa-pen-to-square"></i> 公民神演練！
> 大量使用塑膠吸管所造成的健康與海洋生態破壞問題讓人擔憂。假定某國的民意強烈要求政府應立刻大幅限制塑膠吸管的使用，且依據現行法律，主管機關已有充分法律授權可發布命令、訂定實施細則與開始日期，以管制塑膠吸管使用；但該機關卻認為茲事體大，仍依循該國法律對制訂行政命令的過程，預先將草案公告周知，並依法舉辦聽證，廣納各界意見，再審慎決定規定內容。請問從外部成本的觀點，下列敘述何者符合該國政府政策的意涵？【111. 學測】  
> (A) 社會成本高於私人成本，從市場經濟的觀點塑膠吸管的生產數量過多  
> (B) 社會成本高於私人成本，從整體社會的觀點塑膠吸管的生產數量過多  
> (C) 私人成本高於社會成本，從市場經濟的觀點政府應管制塑膠吸管使用  
> (D) 私人成本高於社會成本，從整體社會的觀點政府應管制塑膠吸管使用  
> 
> **【參考答案】(B)**  
> *解析：使用塑膠吸管會破壞海洋生態並危害健康，造成「負外部性（外部成本）」。此時：$\text{社會成本} = \text{私人成本} + \text{外部成本} > \text{私人成本}$。在未受管制的市場中，廠商僅依私人成本決策，導致從「整體社會最適福祉的觀點」來看，市場實際生產的數量過多（高於社會最適產量）。故 (B) 最合乎題意。*

## 重點 2｜為何政府需要關心廠商的聯合行為？

### 一、廠商競爭所採取的方式

* **價格競爭**：透過**降價或搭配其他促銷方案**，依需求法則吸引消費者增加購買量（例如：知名連鎖咖啡買一送一、百貨公司週年慶滿千送百）。
* **非價格競爭**：透過研發與設計，生產與同業相異之「**差異化服務**」或更高品質商品，因應客製化需求以突顯特色（例如：藍牙耳機提供雷射雕刻客製化文字、延長保固服務）。

---

### 二、廠商的漲價行為與效果

```
廠商漲價行為比較
 ├─ 單一廠商漲價 ── 市場具替代選擇 ──► 消費者轉移陣地 ──► 該廠商面臨客源流失與銷量下滑風險
 └─ 廠商聯合漲價 ── 業者私下協議 ───► 市場失去競爭機制 ──► 剝削消費者剩餘、造成社會無謂損失
```

| 行為面向 | 原因說明 | 市場效果 |
| :--- | :--- | :--- |
| **單一廠商漲價** | 為追求最大利潤，或因應原物料、人力成本上漲。 | 若其他廠商不跟進，消費者基於自利將轉向其他替代廠商消費，漲價廠商將面臨客源減少與銷量下跌。 |
| **廠商聯合漲價<br>（聯合壟斷）** | 產品性質相近之同業事先約定好，不在價格上競爭，採取一致的提價策略並瓜分市場。 | 1. **嚴重減損市場競爭性**，迫使消費者承擔高昂價格，直接剝奪消費者剩餘。<br>2. 造成市場產量縮減，產生**無謂損失**，嚴重減損經濟效率。<br>3. 廠商坐享暴利，喪失投入創新研發或改善服務之動力。 |

---

### 三、政府如何因應廠商間的漲價行為？

#### 1. 法源依據與主管機關
* **法源依據**：《公平交易法》。
* **主管機關**：行政院轄下獨立機關——**公平交易委員會（公平會）**。
* **立法宗旨**：維護交易秩序與消費者利益，確保自由與公平競爭，促進經濟之安定與繁榮。

#### 2. 公平會管制的行為範疇

| 管制項目 | 具體禁止行為 | 實務舉例 |
| :--- | :--- | :--- |
| **限制競爭行為** | 阻礙其他業者競爭，或不當控制原物料供應、價格等作為，意圖影響市場秩序（**獨占、結合、聯合行為**）。 | 同業公會私下開會統一調漲民生必需品售價；大型超商聯合約定現煮咖啡同日齊漲。 |
| **禁止不公平競爭行為** | 1. **廣告不實**：宣稱產品效能優異，以虛偽誇大不實方式引人錯誤。<br>2. **侵害營業秘密**：不當竊取他廠專利製程或配方。<br>3. **不正當獲取交易機會**：以暴力、脅迫或顯不合理之贈品利誘，阻礙同業競爭。 | 瘦身食品宣稱一週速效瘦身；生技大廠高薪挖角工程師竊取晶片機密配方。 |

#### 3. 調查與處罰機制
* 主管機關得依市場狀況、商品特性、成本利潤及經濟合理性等客觀因素「**推定**」業者之合意聯合行為。
* 業者須主動舉證其定價為獨立核算；若查證屬實違反規定，公平會得依法處以罰鍰，情節重大者可加重裁罰並命限期改正。

## 重點 3｜外部效果對於日常生活的影響

### 一、外部效益與外部成本的影響分析

```
【外部效益（正外部性）圖解】                     【外部成本（負外部性）圖解】
  價格 (P) ▲                                      價格 (P) ▲
          │                                              │      S2 (社會成本線 = 私人成本 + 外部成本)
          │             S (私人成本線 = 社會成本線)       │     ／ 
        P2┼─────────── E2 (社會最適點)                P2┼─── E2 (社會最適點)  S1 (私人成本線)
          │          ／   ＼                             │  ／   ＼           ／
        P1┼─── E1   ／       ＼                         P1┼─ E1   ＼       ／
          │   ／ ＼／           ＼ D2 (社會效益線)        │／ ＼     ＼   ／
          │ ／   ／＼             │                      │    ＼     ＼／ 
          │/    /    ＼           │                      │      ＼   ／ ＼
          │    /       ＼ D1 (私人效益線)                │        ＼/     ＼ D (社會效益線)
        0 └───┴─────────┴────────► 數量 (Q)           0 └─────────┴───────┴──────► 數量 (Q)
              Q1        Q2                                       Q2      Q1
            (市場)    (社會)                                   (社會)  (市場)
  【現象】：市場產量 Q1 < 社會最適 Q2（生產不足）     【現象】：市場產量 Q1 > 社會最適 Q2（生產過多）
  【對策】：政府給予【補貼】，引導產量增至 Q2         【對策】：政府予以【課稅／管制】，使產量降至 Q2
```

| 比較項目 | 外部效益（正外部性） | 外部成本（負外部性） |
| :--- | :--- | :--- |
| **定義** | 經濟行為對第三人（社會）產生正面效果，提高福祉，但第三人不用付出代價（享受好處／搭便車）。 | 經濟行為對第三人（社會）帶來成本或負面傷害，減損第三人福祉，但行為人並未為此付出代價。 |
| **成本與效益關係** | **私人效益 $<$ 社會效益**<br>（$\text{社會效益} = \text{私人效益} + \text{外部效益}$） | **私人成本 $<$ 社會成本**<br>（$\text{社會成本} = \text{私人成本} + \text{外部成本}$） |
| **市場失靈結果** | 利益無法全部歸自己所有，導致**市場交易數量太少（$Q_1 < Q_2$）**，社會福利未達極大。 | 損害由他人承擔，缺乏節制誘因，導致**市場交易數量過多（$Q_1 > Q_2$）**，造成社會福利淨損失。 |
| **生活實例** | 注射傳染病疫苗、老屋整修拉皮美化市容、鄰舍裝設夜間路燈。 | 工廠排放廢水廢氣、汽機車排氣污染、公共場所吸二手菸。 |
| **政策因應對策** | 政府採取**補貼政策**或公費提供，獎勵誘使產量增加至社會最適水準。 | 政府採取**課稅（皮古稅）、罰鍰、總量管制**，將外部成本內部化。 |

---

### 二、政府如何解決外部效果問題？

```
                         ┌─ 外部效益 ──► 補貼（如：育兒補貼、疫苗公費補助）
                         │
             ┌─ 類型 ────┼─ 外部成本 ─┬─ 直接管制（如：禁菸區、排氣標準標準）
             │           │           ├─ 使用者付費（如：隨袋徵收、排污費）
             │           │           └─ 課稅（如：碳稅、能源稅）
             │           │
市場失靈 ────┤           ├─ 財產權不明 ──► 建立財產權（寇斯定理：碳權交易、排放權拍賣）
（外部效果） │           │
             └─ 原因 ────┼─ 資訊不對稱 ──► 資訊公開（如：履歷標籤、實價登錄）
                         │
                         └─ 交易成本過高 ─► 累積社會資本（誠信互信、標準化規格降低比價成本）
```

#### 1. 解決途徑與方法詳解

| 因應面向 | 問題說明 | 政府解決方法與政策機制 |
| :--- | :--- | :--- |
| **外部成本內部化<br>（庇古手段）** | 行為人未負擔破壞環境或公共秩序的成本。 | 1. **課稅與收費**：課徵碳稅、空污費、垃圾隨袋徵收。<br>2. **直接法律管制**：公告空氣品質標準、設立禁菸區。 |
| **外部效益內部化** | 行為人提供公共利益卻無法回收成本，致產量偏低。 | 1. **發放補貼**：提供購買電動車補助、造林獎勵金。<br>2. **公辦公營**：由國家免費施打傳染病公費疫苗。 |
| **財產權歸屬明確<br>（賦予財產權）** | 財產權不明確將形成「**共有財的悲劇**」（如海洋魚群遭過度濫捕、攤販廢水隨意傾倒水溝），因缺乏所有權人監督維護。 | **依據「寇斯定理（Coase Theorem）」**：<br>在「**交易成本極小**」且「**財產權界定明確**」下，雙方可透過自願協商交易將外部成本內部化，使資源配置達到效率。<br>*例*：建立**可交易的廢水／碳排放權市場**。 |
| **資訊透明公開** | 交易雙方資訊不對等產生外部成本（如電信資費陷阱、就醫隱瞞病情）。 | 制定法規強制**資訊公開與定型化契約規範**，保障買賣雙方取得對等、正確之商品履歷與成分資訊。 |
| **降低交易成本** | 蒐集資料、談判協商、簽約檢驗之成本過高將阻礙交易。 | 建立公平交易法制，增進社會**社會資本（互信機制）**，推動產品透明標示與售價，省去處處比價之困擾。 |

* *註（政府失靈）*：政府干預自由市場若缺乏充分資訊或受利益團體遊說，反而可能導致行政效率低落、資源錯置，造成更嚴重的無謂損失。

> ### <i class="fa-solid fa-pen-to-square"></i> 公民神演練！
> 小麗長期關注水源區環境保護，她最近在一項公職人員選舉中獲勝。她的政見主要有兩項：一是當選後要修法禁止所有水源區設立工廠，以保護流入水源區的水流；二是水源區之外，也要立法實施廢水排放總量管制；政府可拍賣廢水排放執照，並容許廠商間交易廢水排放權。請問在廠商可以交易廢水排放權的情況下，若交易價格持續下降，其原因最可能為下列何者？【110. 學測】  
> (A) 由政府首輪拍賣出去的廢水排放權數量過少  
> (B) 水污染防治比原先政府估計的成本低且容易  
> (C) 社會大眾抗議污染導致排放權交易不夠熱絡  
> (D) 能夠透過出售排放權而獲利的廠商數量太少  
> 
> **【參考答案】(B)**  
> *解析：排放權交易市場的價格由排放權的「供給與需求」決定。廠商對排放權的需求，取決於其自身的「污染減排（防制）成本」。若水污染防制技術突破、成本遠比預期更低且容易達成，廠商寧可自行淨化防制而不需購買排放權，導致市場對排放權的**需求大幅減少（線左移）**，造成排放權的**交易價格持續下跌**。故選 (B)。*

## 重點多元跨領域題組｜實戰閱讀與深度思辨

### 【閱讀文章】
新世代能源車除了純電動車外，日本豐田汽車（Toyota）也押寶在氫燃料車，2014 年開賣的「未來（Mirai）」氫燃料電池車，推出第二代，除了價格更便宜，續航力更來到 850 公里。氫燃料車是透過氫氣來做為燃料，由於行駛時只會排出水，無二氧化碳，被稱為是真正環保的能源車。對此，日本首相在官邸試乘了「未來」，稱「這是氫時代的序幕」。

<u>氫燃料電池車的工作原理是，讓儲罐中的氫與空氣中的氧發生反應產生電能，使引擎轉動從而帶動汽車行駛。行駛過程只會排放水，不會產生大氣汙染物和溫室氣體，因此被視為「終極環保車」。日本政府為購車和設置加氫站提供鉅額補貼</u>，希望通過政府和產業界聯手將燃料電池車培育為下一代汽車的主力，但也有觀點對燃料電池車的環保性能表示懷疑，原因在於生產氫的過程將產生溫室氣體二氧化碳。

美國汽車協會的一項調查顯示，三分之一的受訪者表示，下次買車時有興趣購買油電混合車——既有內燃引擎、也有電動引擎的汽車；而考慮購買電動車的受訪者，最重視兩個因素：42 %表示關心環境，31 %表示希望降低長期成本；另外在表示不考慮購買油電混合車的受訪者當中，超過三分之一表示，他們最關注的是車價較高。

2. 若日本政府因補助「未來」車款購車費用之政策，遭國內其他車商抗議政府此舉是圖利特定廠商，將不利於廠商之間公平競爭，請問下列敘述何者正確？  
> (A) 其他汽車廠商仍可以價格競爭方式，透過降價與「未來」競爭，因此不成立

3. 請問根據文中美國汽車協會的調查結果，下列何者最為正確？  
> (A) 電動汽車市場主要的問題在於由少數業者獨占，因此車價居高不下  
> (B) 對於不考慮購買油電混合車的受訪者而言，存在資訊不對稱的問題  
> (C) 傳統汽油車普遍較油電混合車價格低廉，屬於廠商的價格競爭手段  
> (D) 對有興趣購買油電混合車的受訪者而言，決策時考慮到非價格因素  
> 
> **【參考答案】(D)**  
> *解析：調查中 42% 受訪者因「關心環境」而考慮購買，環境關懷並非商品價格本身，屬於影響消費者決策的「非價格因素」。*

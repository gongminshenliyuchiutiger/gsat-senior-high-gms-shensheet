# 單元 9　行政法與行政救濟（法律篇）

---

## 重點 1｜行政法與人民生活

### 一、行政法的意義與功能

#### 1. 意義與內涵
* **意義**：強調法治主義，重視依法行政的法律領域。凡與行政機關執行管理有關的法律統稱為行政法，**屬於國內公法**。
* **內涵**：我國**沒有一部名為《行政法》的統一法典**，只要與行政權有關的各項法規都統稱為行政法，旨在規範行政機關的行政行為，避免侵害人民權利，為**憲法的具體化**（涵蓋《行政程序法》、《行政訴訟法》、《訴願法》等）。

#### 2. 行政法的功能與實例

| 功能面向 | 核心意涵 | 具體法規與作用舉例 |
| :--- | :--- | :--- |
| **維護公共利益與實現正義** | 促進公共資源有效利用，改善國民生活品質與扶助弱勢。 | 1. 《土地徵收條例》：促進土地有效利用。<br>2. 《都市更新條例》：提升都市居民生活品質。<br>3. 《社會救助法》：核定與補助中低收入戶，扶助社會不利處境者。 |
| **保障人民權利** | 規範公權力行使，保障人民生命、身體、自由與財產權。 | 1. 《行政程序法》：確保依法行政，保障人民權益。<br>2. 《消防法》：保障人民生命、身體、財產安全。<br>3. 《兒童及少年福利與權益保障法》：落實兒少人權保障。<br>4. 《國民教育法》：落實憲法保障受國民教育之權利與義務。 |
| **兼顧公共利益與人權保障** | 在維護公共秩序與公共安全的同時，兼顧人民基本權利之衡平。 | 1. 《食品安全衛生管理法》：不合格食品強制下架，維護人民飲食安全。<br>2. 《道路交通管理處罰條例》：供行人通行之騎樓、走廊不得堆置障礙物，保障人民用路安全。 |

---

### 二、行政法規範的範圍

```
行政法規範範圍
 ├─ 行政組織法 ── 規範代表國家或地方自治團體之組織（如：臺北市政府、宜蘭縣頭城鎮公所）
 ├─ 行政作用法 ── 規範行政行為之實質要件與法律效果（如：罰鍰、勒令停業、吊銷執照）
 ├─ 行政程序法 ── 規範行政機關從事行政行為之法定手續（如：程序公開、聽證、資訊公開）
 └─ 行政救濟法 ── 規範人民不服行政行為之救濟管道（如：訴願先行程序 ─► 訴願 ─► 行政訴訟）
```

---

### 三、國家介入人民的行政手段

| 類型 | 干預行政（不利）／負擔處分 | 給付行政（有利）／受益處分 |
| :--- | :--- | :--- |
| **內涵** | 國家基於公共利益、維持社會秩序，採取**強制性措施**，干預人民權利、限制人民自由與財產，或課予人民義務與負擔。 | 國家為保障基本人權，提供各項**社會福利措施**（補助或服務），或提供獎勵引導人民與民間機構協助政策達成。 |
| **例子** | 強制繳稅、取締違規停車、對違法廠商開罰。 | 全民健保、社會救助生活扶助、育兒津貼發放。 |

## 重點 2｜行政法的一般原理原則

```
行政法原理原則
 ├─ 依法行政原則 ─┬─ 法律保留原則（積極）：行政行為必須有法律依據或明確授權
 │               └─ 法律優越原則（消極）：行政行為與命令不得牴觸憲法與法律
 ├─ 比例原則 ────── 適當性、必要性（最小侵害）、狹義比例性（衡量性）
 ├─ 平等原則 ────── 行政自我拘束、禁止恣意原則（等者等之，不等者不等之）
 ├─ 明確性原則 ──── 法律明確性、授權明確性、行政行為明確性
 ├─ 信賴保護原則 ── 人民信賴國家公權力措置，其正當合法利益應受保護（不溯及既往）
 ├─ 誠實信用原則 ── 行政機關與人民互負誠信，不得出爾反爾
 ├─ 裁量合法適宜 ── 行使裁量權不得逾越法定範圍，應合乎授權目的
 └─ 禁止不當聯結 ── 行政手段與欲達成之目的間，必須存在合理實質關聯
```

### 一、依法行政原則（行政法的核心）

```
                     ┌── 1. 行政行為不得與憲法、法律相牴觸
行政行為 ─► 法律優越 ┤
         │           └── 2. 下級規範不得逾越上級規範
         │
         │           ┌── 1. 行政行為必須有法律規定或明確授權
         └─► 法律保留 ┤
                     └── 2. 行政機關不可逕行自定命令限制人權
```

| 區別 | 法律優越原則（消極的依法行政） | 法律保留原則（積極的依法行政） |
| :--- | :--- | :--- |
| **定義** | 所有行政行為均須受現行有效法律拘束，**不得有違反法律**之行為。 | 行政機關為行政行為（特別是干預行政），**必須要有法律依據**才能為之。 |
| **核心觀念** | 行政法規命令與處分，不能牴觸法律規定或逾越法律授權範圍。 | 須經立法機關制定法律明定後，行政機關方得依法執行，不得恣意為之。 |
| **舉例** | 警察取締噪音之行政行為，不得牴觸《噪音管制法》之標準。 | 內政部須依《政黨法》規定或授權，才能對違規政黨開罰，不可逕行懲罰。 |

---

### 二、比例原則（憲法第 23 條、行政程序法第 7 條）

* **定義**：行政機關不能以侵害人民權益更大的手段達成目的，必須以適當合理之手段為之。
* **三大子原則與個案檢驗（以拒絕酒測處罰為例）**：

| 子原則 | 檢驗標準 | 手段 ①：終身吊銷駕照 | 手段 ②：吊銷駕照 3 年 |
| :--- | :--- | :---: | :---: |
| **適當性原則** | 手段是否有助於目的（遏止酒駕、保障交安）之達成？ | 通過（<i class="fa-solid fa-check text-success"></i>） | 通過（<i class="fa-solid fa-check text-success"></i>） |
| **必要性原則** | 是否為所有能達成目的手段中侵害最小者？ | **不通過（✘）**<br>侵害權益過大 | 通過（<i class="fa-solid fa-check text-success"></i>）<br>損害較小 |
| **衡量性原則<br>（狹義比例性）** | 手段所造成之損害，與達成目的之利益是否相當？ | **不通過（✘）**<br>手段過度侵害，失衡 | 通過（<i class="fa-solid fa-check text-success"></i>）<br>兼顧公私利益 |
| **結論** | 處罰吊銷駕照 3 年符合比例原則。 |

### 三、其他重要原理原則詳解

| 原則名稱 | 定義說明 | 實務舉例與禁制規範 |
| :--- | :--- | :--- |
| **平等原則** | 相同事物應為相同處理，不同事物應為不同處理；非有正當理由，不得為差別待遇。 | 不論何人興建建物，只要符合法規，主管機關均應核發建照；**不得主張「不法的平等」**（他人違法未受罰，不得據此要求自己也不受罰）。 |
| **明確性原則** | 行政行為之內容、目的、施行範圍須具體窮盡、明確可行，使人民能充分預見與理解。 | 《兒少權益保障法》第 49 條詳列 15 種不得對兒少為之的行為，並明定罰鍰金額幅度。 |
| **誠實信用原則** | 行政機關與人民行使權利、履行義務，應恪守誠信；機關不得出爾反爾、強人所難。 | 市府命違建戶 15 日內自行拆除，若政府在期限屆滿前即進場強拆，即屬違反誠信原則。 |
| **信賴保護原則** | 人民因信賴公權力措置之有效存續而有所規劃，其信賴利益應受保護；法規**不溯及既往**。 | 學生申請就學貸款，政府事後修改還款條件，除非新法更有利，否則應依申請時法規辦理。 |
| **裁量合法適宜** | 行政機關行使法律賦予之裁量權時，不得逾越法定範圍，並應符合授權之客觀目的。 | 《道交條例》規定闖紅燈處罰鍰 1,800～5,400 元，機關開罰金額須在此區間內依情節決定。 |
| **禁止不當聯結** | 行政機關所採取的手段，與其所欲追求之目的間，**必須具備合理實質的正當關聯**。 | 車主申請換發行照，監理機關以「未繳清超速罰單」為由退件拒發，兩者無實質因果，違反此原則。 |

> ### <i class="fa-solid fa-pen-to-square"></i> 公民神演練！
> 某公司從某國進口符合該國食用油標準之食用油，但進口時為逃避繁瑣的進口檢驗，刻意選擇「工業用途」名義以加速通關。相關食安法律規定，申報不實得處新臺幣三百萬元以下罰鍰。某市政府查獲該公司申報不實後，決定處以最高額度的罰鍰。該公司不服，依前述，該公司若要提起行政訴訟，訴訟攻防中可以主張的法律原則為下列何者？【改自 112. 學測】  
> (A) 正當程序  
> (B) 比例原則  
> (C) 信賴保護  
> (D) 誠實信用  
> 
> **【參考答案】(B)**  
> *解析：主管機關裁罰時享有裁量權，但裁量時必須衡量違規情節輕重。若主管機關未視實際情節（油品實質符合食用標準），直接逕處「最高額度 300 萬元罰鍰」，可能構成裁量怠惰或過度處罰，公司在訴訟中最適宜主張處分違反了「手段與損害失衡」的**比例原則**。*

## 重點 3｜正當行政程序

### 一、正當行政程序的意義與核心理念

* **定義**：行政機關做成各種行政行為時，所應嚴格遵循的法定法定步驟與程序。
* **目的**：實踐民主參與、確保依法行政、保障人民權益、提升政府行政效能。

```
行政行為 ──► 民主程序 ＋ 公開程序 ＋ 公正程序（程序正義） ──► 符合實質正義的行政行為
```

---

### 二、正當行政程序之基本原則

#### 1. 民主原則
* **基本定義**：做成決定前給予相對人及利害關係人說明、答辯與防禦機會，綜合考量各方事證。
* **聽證會**：涉及重大公益或爭議事件，行政機關應公開舉行聽證程序，聽取雙方言詞辯論（**三要素：書面通知、公開舉行、言詞辯論**）。聽證結果對主管機關具有**實質拘束力**。
* **陳述意見**：行政機關做成限制或剝奪人民自由權利之處分前，應給予當事人以書面或言詞陳述意見之機會。

#### 2. 公開原則
* **政府資訊公開**：以**主動公開為原則，被動公開為例外**。
  * *目的*：避免資訊不對稱、賦予當事人主張及維護利益之權利。
  * *內容*：當事人得閱覽、抄錄、複印、攝影卷宗。
  * *限制公開事項*：國家機密、個人隱私、工商營業秘密、考試題目、偵查秘密等。
* **合法通知送達**：行政處分做成後應盡合法通知義務（書面送達、公告），處分始正式生效。

#### 3. 公正原則
* **定義**：遵守差別待遇禁止，杜絕程序外不當接觸與偏私。
* **公務員迴避義務**：
  1. **自行迴避（公務倫理）**：承辦人為事件當事人，或與當事人具配偶、前配偶、四親等內血親、三親等內姻親關係者，應自行迴避。
  2. **申請迴避**：公務員有利益衝突而未自行迴避時，當事人或利害關係人得具狀申請其迴避。
  3. **職權命其迴避**：由機關首長或單位主管依職權主動命令該公務員迴避。
* **組織適法原則**：機關應依法定組織開會做成決定（合法出席與表決門檻）。
* **禁止不當接觸**：行政人員不得與當事人於程序外私下進行不必要的接觸。

---

### 延伸補充：聽證會 vs. 公聽會之比較

| 比較項目 | 聽證會（Formal Hearing） | 公聽會（Public Hearing） |
| :--- | :--- | :--- |
| **程序性質** | **法定正式程序** | **非正式諮詢程序** |
| **舉辦目的** | 釐清法律與事實爭議，主管機關有**說明採納與否之義務**。 | 廣泛聽取利害關係人意見，**僅供決策機關參考與彙整**。 |
| **實質效力** | **聽證紀錄具實質拘束力**，處分必須斟酌聽證結果。 | 主管機關不受約束，亦無逐一答辯說明之義務。 |
| **發言紀錄** | 嚴格載明陳述、發問、證據及異議事由。 | 僅記載會議大概情形。 |
| **參與人員** | 受主管機關通知之當事人、利害關係人及專家證人。 | 民意代表、專家學者、民間團體及一般社會大眾。 |

## 重點 4｜行政救濟

### 一、行政救濟的概念與架構

* **定義**：當人民遭受行政機關**違法或不當**之行政行為侵害，導致權益受損時，依法向國家請求予以補救之法律制度。

```
【第一階段：先行程序】（法律有特別規定時）
  稅捐爭議（復查）／專利審查爭議（再審查）／商標審查爭議（異議、評定）
         │
         ▼
【第二階段：行政內部自我審查】
  訴  願（向原處分機關之上級行政機關提起）
         │
         ▼（不服訴願決定，於 2 個月內提起）
【第三階段：外部司法審查】
  行政訴訟（向行政法院提起，採「三級二審制」）
```

---

### 二、訴願與訴訟程序規範

#### 1. 訴願（行政內部審查）
* **程序要件**：人民對於行政處分認為違法或不當致損害權利，於收到處分書之次日起 **30 日內**，向原處分機關的上級機關提出。
* **例外情形**：未涉及高度專業性或大量做成的集體處分，有時得依法律規定免經訴願，逕提行政訴訟。

#### 2. 行政訴訟（司法救濟）
* **審理架構（三級二審制）**：
  * **第一級**：高等行政法院「地方行政訴訟庭」（原各地院行政訴訟庭改制合併）。
  * **第二級**：高等行政法院「高等行政訴訟庭」。
  * **第三級**：最高行政法院。
* **保障功能**：確保行政爭議當事人享有受法院公正審判與至少一次上訴的救濟權利。

---

### 三、各類行政救濟之實務案例流程

#### 案例 1：輕微行政處分（簡易訴訟程序）
* **案情**：阿哲隨地亂丟菸蒂，被 A 市環保局裁罰 3,600 元，因採證照片模糊而不服。
* **救濟路徑**：
  1. 向 A 市政府提出**訴願**。
  2. 不服訴願決定 $\rightarrow$ 行政訴訟第一審：**高等行政法院地方行政訴訟庭**。
  3. 不服第一審判決 $\rightarrow$ 行政訴訟第二審（終審）：**高等行政法院高等行政訴訟庭**。

#### 案例 2：重大行政處分（通常訴訟程序）
* **案情**：經濟部核發採礦權展延給水泥公司，太魯閣族人認為違背《原基法》而提起抗爭。
* **救濟路徑**：
  1. 向行政院提出**訴願**。
  2. 不服訴願決定 $\rightarrow$ 行政訴訟第一審：**高等行政法院高等行政訴訟庭**。
  3. 不服第一審判決 $\rightarrow$ 行政訴訟第二審（終審）：**最高行政法院**。

#### 案例 3：學生權益救濟（申訴、再申訴與訴訟）
* **案情**：高三學生小茜因缺課時數問題未獲發畢業證書，不服校方處分。
* **救濟路徑**：
  1. 向學校**學生申訴評議委員會（申評會）** 提出**申訴**。
  2. 不服申訴決定 $\rightarrow$ 向主管機關（教育部或地方教育局）提出「**再申訴**」（**視同訴願**）。
  3. 不服再申訴決定 $\rightarrow$ 依案件性質提請行政訴訟：
     * 簡易案件：高等行政法院地方行政訴訟庭 $\longrightarrow$ 高等行政訴訟庭。
     * 通常案件：高等行政法院高等行政訴訟庭 $\longrightarrow$ 最高行政法院。

### 延伸補充：高中生的權利救濟與司法實務（司法院釋字第 784 號）

* **法律背景**：
  * 過去實務受限於「特別權力關係」，學生對於未達退學或侵害受教育權的處分不得提起行政訴訟。
  * **大法官釋字第 784 號解釋**打破限制：基於《憲法》第 16 條有權利即有救濟之意旨，各級學校學生認其權利因學校教育或管理等公權力措施遭受侵害時，**即使非屬退學或類似處分，均得按情節提起相應之行政爭訟程序尋求救濟**。
* **《高級中等教育法》第 54 條規定**：
  1. 學生或學生自治組織對學校處分、措施認為違法或不當致損害權益，得向學校提出**申訴**。
  2. 不服申訴決定，得向主管機關提出**再申訴**。
  3. 原處分性質屬行政處分者，其**再申訴決定視同訴願決定**；不服再申訴決定者，得依法提起**行政訴訟**。

# 單元 3　民主治理與政府體制（社政篇）

---

## 重點 1｜當代民主國家的運作

### 一、憲政主義的精神

| 核心概念 | 內涵說明 |
| :--- | :--- |
| **當代政府的特徵** | 在於可以**合法使用武力權威**的社會組織。但民主政治的精神主要在於對權力謹慎使用，避免侵害人民的權利，因此期許建立的是一個「**權責相符**」的政府。<br>*(權力：個人或國家以控管、支配的方式對他人產生強制性的力量；權利：法律規定人民應享有的利益，國家不得非法侵犯)* |
| **權責相符定義** | 「權力」和「責任」相符合，**權力愈大，責任愈大**。 |
| **檢驗方法** | 1. **民主的憲政體制**：政府的權力與政治運作**應受憲法規範**，以保障人民的自由與權利，包括責任政治、民意政治、法治政治。<br>2. **穩定的文官制度**：在健全的法令規範下，公務人員配合政府機關提供專業及有效率的行政服務，成為政府中的穩定力量。 |

---

### 二、憲政主義的落實

```
憲政主義的落實
 ├─ 責任政治 ─┬─ 政治責任（政策違背民意或成效不彰時：道歉、辭職下臺）
 │            └─ 法律責任（官員違法失職、貪汙時：負起刑事、行政責任）
 ├─ 民意政治 ─┬─ 政治平等（人民在政治上一律平等，如投票一人一票）
 │ （人民主權  ├─ 公共參與（具備慎思明辨能力，並能接納不同意見）
 │   國原則）  ├─ 定期選舉（展現民意、汰換不良政客、落實政黨競爭機會）
 │            └─ 多數統治（以多數決為決策基礎，但仍須尊重少數人權益）
 └─ 法治政治 ─┬─ 守法社會（人民依法律規範預測彼此行為，形成自發性秩序）
   （分立原則  ├─ 依法行政（政府與公職人員皆需遵守法令制度，不能違法濫權）
   司法審查制）└─ 司法獨立（政府不守法時，人民可透過獨立的司法進行救濟）
```

## 重點 2｜民主治理

### 一、民主治理的背景與內涵

#### 1. 政府角色的轉變
* **17～18 世紀（君主專制 $\rightarrow$ 有限政府）**：受憲法和法律約束的政府，強調消極不干預。
* **19～20 世紀（資本主義興起 $\rightarrow$ 萬能政府）**：造成貧富不均與勞資對立，人民期許政府積極介入解決社會問題。
* **20～21 世紀（效能政府）**：提倡「企業型政府」，追求高品質、高效率、善治治理。

#### 2. 治理的核心概念
* **內涵**：除重視政府的效率與效能外，強調**政府與民間社會積極有效的合作**。
* **目標**：透過公共服務，達成「保障人民權利」與「追求社會福利」的目標，並防止政府貪腐現象發生。
* **多元行動主體**：
  * **第一部門（公部門）**：政府機關（公權力組織），目的在於**執行國家意志**。
  * **第二部門（私部門）**：企業組織，目的在於**營利**。
  * **第三部門（志願部門）**：非營利組織（NPO/NGO），目的在於**關切公共事務**。
* **權力行使模式**：政府與民間社會建立「**公私夥伴關係**」，共同協力處理地方公共事務；結合地方人力與資源，培養公民的民主素養。

---

### 二、民主治理的課責與落實方式

#### 1. 課責的四個面向
* **課責性**：公職人員與政府部門需為自身行為負責，透過定期選舉、議會與輿論監督進行課責（屬外部課責）。
* **透明性**：行政過程「制訂與施行公開透明」（屬內部課責）。
* **回應性**：政府應滿足人民真實需求，快速回應民意（屬內部課責）。
* **代表性**：政府制定政策時要考量人民的多元性，避免忽略弱勢群體，落實公平與正義（屬內部課責）。
* *(效率：能否以較少的經費、人力、時間完成較佳的施政成果；效能：衡量工作目標最終的達成度)*

#### 2. 治理的落實方式
* **法人化**：由政府出資成立不屬政府部門的機構來推動業務（如：國家運動訓練中心、國家表演藝術中心等行政法人）。
* **去任務化**：解除政府管制，開放市場競爭；將國營企業轉為民營（如：中華電信民營化）。
* **委外化**：在不影響品質下將業務交由民間執行，降低人事成本並鼓勵民間投資（如：高雄捷運、新北市立土城醫院 BOT 案）。
* **地方化**：將中央主管業務交由地方政府辦理，使權力分散、更貼近在地需求（如：新北市紅毛城由內政部移交新北市管理）。
* **電子化**：透過資通訊科技串聯政府、民眾與資訊，建立互動系統，提供即時完整的資訊與服務。

---

### 三、公民參與治理——以參與式預算為例

* **定義**：由人民來決定一部分公共預算的支出。
* **內涵**：打破傳統「由上而下單純接受政策」的模式，讓人民將最直接的在地需求轉化為公共服務；預算執行過程公開透明，落實公眾課責。
* **四大目標**：
  1. **包容**：鼓勵廣泛公眾參與，使人人有機會討論及決定公共資源。
  2. **審議**：鼓勵公眾透過說理、學習、溝通與討論的過程參與公共預算決定。
  3. **決定**：賦予一般民眾決定公共支出優先順序的權力，並對候選預算方案進行投票。
  4. **社會正義**：改變傳統由菁英結構分配預算的模式，讓資源分配兼顧弱勢群體，使境況較差者受益。

## 重點 3｜民主國家的政府體制

### 一、政府體制之分類標準
依「**行政權的歸屬**」以及「**行政權和立法權的關係**」分類：

```
                    ┌── 內閣制（英國代表）：虛位元首、行政權與立法權融合
                    │
民主國家的中央政府 ─┼── 總統制（美國代表）：實權元首、行政權與立法權分立
                    │
                    └── 混合制／雙首長制（我國代表）：總統（對外）與行政院長（對內）各有實權、行政與立法分立
```

---

### 二、內閣制（盛行於歐洲，以英國為例）

```
                        ┌────── 解散國會 ──────┐
                        │                      ▼
虚位元首（國王／總統）──┼── 任命多數黨組閣 ──► 內閣（行政：總理／首相）
   ▲                    │                      ▲
   │                    └─ 呈請解散 / 副署法令 ─┘
   │ 代議                                      │ 提法律、預算、施政報告
   │ 選舉                                      │ ────────────►
人民 ───────► 國會（立法：下議院）───────────────┘
                               ◄────────────
                                通過法律、預算 / 不信任案 / 質詢
```

#### 1. 核心體制特徵
* **代表國家**：英國、日本、西班牙、荷蘭、德國、新加坡。
* **虛位元首**：由世襲（英、日）或選舉產生（德、新加坡），政治地位維持超然中立，**不參與決策、不負政治責任**。
* **行政與立法融合**：
  * 行政權屬於內閣；由下議院多數黨領袖出任首相組閣。
  * **閣揆及閣員皆具國會議員身分**，兼掌行政權與立法權。
* **副署制度**：元首發布法令需經首相或相關閣員**副署**；由內閣承擔實質政治責任，元首不得拒絕簽署副署議案。
* **內閣向國會負責（倒閣與解散）**：
  * 國會可對內閣提出**不信任案（倒閣案）**。
  * 若通過，內閣有兩種因應途徑：
    1. **內閣總辭**：讓國會多數支持的新領袖重新組閣。
    2. **解散國會**：呈請元首解散國會重新大選，訴諸最新民意裁判。
  * 若不信任案不通過：化解憲政危機，行政與立法關係趨於穩定。
* **政黨運作**：
  * 最大在野黨可組成「**影子內閣**」監督執政黨。
  * 若無單一政黨過半，可組成「**聯合內閣**」或由少數席次組成「**少數內閣**」。

#### 2. 優缺點評析
* **優點**：元首超然超脫政黨，有利維持政局穩定；行政立法融合，政策推行有效率；設有倒閣與解散機制，易於化解僵局。
* **缺點**：執政黨若席次絕對過半且在野力量薄弱時，易演變為「**內閣專制**」；多黨林立若常組聯合內閣，易造成內閣頻繁更迭、政府政局不穩。

### 三、總統制（以美國為例）

```
                     ┌─── 人事同意權 / 條約批准權 / 調查彈劾權 ───┐
                     │    審查預算 / 審議法案                     │
國會（立法機關） ◄──┼────────────────────────────┼──► 總統（行政機關）
   ▲                 │    國情報告 / 法律否決權（覆議）           │        ▲
   │                 └───◄────────────────────────────┘        │
   │ 選舉議員                                                選舉人團選出 │
   └─────────────────────── 人民（選民）───────────────────────┘
```

#### 1. 核心體制特徵
* **代表國家**：美國、南韓、菲律賓、中南美洲國家等。
* **實權元首**：
  * 總統由人民直接或間接（選舉人團）選出，身兼**國家元首、最高行政首長與三軍統帥**。
  * 閣員為總統的幕僚，僅對總統負責；由**總統一人承擔全部行政責任**。
  * 總統與幕僚閣員**均不得兼任國會議員**。
* **行政與立法完全分立**：
  * 兩者皆由選民選出，**各自對選民負責**；國會議員與總統均有固定任期保障。
  * **總統無權解散國會**，國會亦不能因單純政治理由令總統去職（僅能於違法失職時發動**彈劾**）。
* **權力制衡機制**：
  * **總統對國會**：對國會通過之法案享有**法案否決權**。
  * **國會對總統**：人事同意權（如參議院對大法官、閣員、駐外使節）、條約批准權、預算審查權（眾議院為主）、國會調查權。
  * **司法審查**：聯邦最高法院得依**司法審查權**宣告行政命令或法律違憲，制衡總統與國會。

#### 2. 優缺點評析
* **優點**：官員與議員任期固定，政府運作穩定；行政權獨立分立，行政首長享有較大行政裁量空間。
* **缺點**：
  * 當總統與國會多數分屬不同政黨時，形成「**分立政府**」（相較於同政黨的「一致政府」），極易產生政務停擺的**政治僵局**。
  * 制度上缺乏倒閣與解散機制，遇政治僵局往往難以迅速化解。

### 四、我國的政府體制（混合制／雙首長制／半總統制）

#### 2. 中央政府權力關係之互動圖解

```
                        ┌── 1. 提案權：彈劾、罷免總統 ──┐
                        ├── 2. 人事同意權                │
                        └── 3. 追認緊急命令              │
                                                          ▼
立法院（國會）◄── 倒閣時被動解散 ── 總 統 ──► 1. 任命行政院長（無須立法院同意）
   ▲                                              └── 2. 核可覆議案
   │ 1. 提出施政報告、接受質詢                     │
   │ 2. 審查法案與預算案                           │
   │ 3. 提不信任案（倒閣）                          │ 副署法律案、命令 /
   │ 4. 議決維持原案                               │ 呈請解散國會
   ▼                                              ▼
行政院（內閣） ──► 移請立法院覆議（經總統核可） ─── 行政院
   ▲                                              ▲
   └────────── 總統對人民施政負責 ───────────────┘
```

#### 3. 兼具總統制與內閣制之特色
* **類「總統制」面向**：
  1. 總統與立委皆由**全民直選**產生，各自享有直接民意基礎，具行政與立法分立精神。
  2. 閣揆由總統直接任命，總統非單純虛位元首，兼具實質行政權力。
* **類「內閣制」面向**：
  1. 行政院院長對總統公布之多數法律及命令具**副署權**。
  2. 行政院向立法院負責：必須提出施政報告、接受質詢、預算案須立院審議。
  3. 立法院對行政院長享有**倒閣權（不信任案）**；行政院得經總統核可後**呈請解散立法院**。

### 五、我國行政與立法的制衡制度詳解

#### 1. 覆議權（行政院 $\rightarrow$ 立法院）
```
立法院通過法律案、預算案、條約案 
  │
  ▼
行政院認為「窒礙難行」 
  │
  ▼
經總統核可後，於決議案送達 10 日內，移請立法院覆議
  │
  ▼
立法院全體立委 1/2 以上決議維持原案 ──► 行政院長須接受該決議
```

#### 2. 不信任案／倒閣（立法院 $\rightarrow$ 行政院）
```
立法院全體立委 1/3 以上連署提出不信任案 
  │
  ▼
全體立委 1/2 以上贊成通過
  │
  ├─► 行政院院長應於 10 日內提出辭職
  │
  └─► 行政院院長得同時呈請總統「解散立法院」（總統宣告被動解散）

*附註：不信任案如未獲通過，一年內不得對同一位行政院長再提不信任案。
```

#### 3. 總統副總統之「罷免」與「彈劾」流程對照

```
【罷免案】（追究政治責任）
立法院全體 1/4 提議 ──► 全體 2/3 同意通過提出 ──► 交公民複決（選舉人總額過半投票，有效票過半同意）

【彈劾案】（追究法律責任）
立法院全體 1/2 提議 ──► 全體 2/3 決議通過提出 ──► 移送司法院憲法法庭審理 ──► 判決成立即解職
```

### 延伸補充：雙首長制的運作模式與行政權二元化

#### 1. 雙首長制各國運作模式
* **權力偏總統**：總統實際權力大於總理，運作偏向總統制（如：我國）。
* **權力偏內閣**：總理權力大於總統，運作偏向內閣制（如：芬蘭）。
* **權力消長（左右共治）**：隨國會多數席次產生權力消長（以**法國**為典型代表）。
  * 總統所屬政黨在國會占多數時 $\rightarrow$ 總統主導國政，偏向總統制。
  * 國會多數黨與總統不同時 $\rightarrow$ 總統依慣例任命國會多數黨領袖出任總理，由總理主導內政，偏向內閣制。

#### 2. 行政權二元化之分工
* **總統（對外為主）**：主導國防、外交、兩岸事務與國家安全重大決策。
* **行政院長（對內為主）**：綜理全國行政事務，負責經濟與內政。

## 重點 4｜中央與地方的權力關係

### 一、單一制與聯邦制之比較

| 比較項目 | 單一制（中央集權） | 聯邦制（地方分權） |
| :--- | :--- | :--- |
| **代表國家** | 法國、日本、英國、中華民國等 | 美國、德國、加拿大、澳洲等 |
| **制度意義** | 治權歸屬於中央，地方政府是中央的**分支機構**，承命辦事。 | 中央與地方各自擁有**憲法保障之獨立權限**，在法定權限內彼此互不相干預。 |
| **權力分配** | 權力集中於中央（概括），地方政府職權需經憲法、法律或行政命令**授權（列舉）**。 | 中央政府之權力由憲法**列舉**；未列舉之剩餘權力通常**概括**歸屬地方政府。 |
| **制度優點** | 權力集中、政令統一度高、行政效率高。 | 地方自治程度高，人民可高度參與地方公共事務。 |
| **制度缺點** | 決策難以因地制宜，無法彈性契合地方特殊需求。 | 資源分散、各邦法令標準不一，不利於推動全國一致性建設。 |

---

### 二、我國中央政府與地方政府的關係

#### 1. 均權制原則與劃分標準
* **劃分原則**：我國憲法採「**均權制度**」，依**事務之性質**劃分中央與地方權限。
  * 事務具有「**全國一致性**」性質者 $\rightarrow$ 劃歸**中央**（如教育制度、國防、外交、貨幣）。
  * 事務具有「**因地制宜**」性質者 $\rightarrow$ 劃歸**地方**（如各級學校設立、地方觀光發展）。
* **法源依據**：《中華民國憲法》、《憲法增修條文》、《地方制度法》、《財政收支劃分法》等。

#### 2. 中央與地方的權限互動型態
* **監督及整合關係**：地方政府對自治事項得自訂法規並執行，但中央依法享有監督權；針對跨區域議題，中央可統籌整合政策以解決爭議。
* **委辦關係**：中央機關依法可將所屬事務委託地方政府辦理（如：辦理兵役徵集、發放振興消費券、辦理中央公職人員選舉選務）。
* **財政關係**：中央依《財政收支劃分法》發放統籌分配稅款與補助款，以平衡區域財政差距；地方依法亦有共同負擔部分跨層級建設費用之義務。
* **地方自治事項**：地方政府享有自主決定之事務（如：社會福利加碼、戶籍行政、觀光發展活動等）。

#### 3. 地方自治團體之層級與組成
* **法定的地方自治團體**：
  * **直轄市**
  * **縣、市（統稱縣市）**
  * **鄉、鎮、市（統稱鄉鎮市）**
  * **直轄市山地原住民區**
* **自治機關之設置**：
  * **行政機關**：負責推動地方自治事務，並執行上級政府之委辦事項。
  * **立法機關**：負責制定自治法規、審查地方總預算，並質詢監督行政機關之施政。

#### 4. 我國地方政府組織架構圖

```
中央政府（行政院）
 │
 ├── 直轄市（地方自治團體）
 │    ├─ 行政機關：直轄市政府
 │    │    ├─ 派出單位：區公所（非自治）
 │    │    └─ 自治團體：山地原住民區公所
 │    └─ 立法機關：直轄市議會
 │         └─ 自治立法：山地原住民區民代表會
 │
 └── 縣／市（地方自治團體）
      ├─ 行政機關：縣政府 / 市政府（基隆、新竹、嘉義）
      │    ├─ 派出單位：區公所（市管轄，非自治）
      │    └─ 自治行政：鄉公所 / 鎮公所 / 縣轄市公所
      └─ 立法機關：縣議會 / 市議會
           └─ 自治立法：鄉民代表會 / 鎮民代表會 / 市民代表會

*註：省政府與省諮議會已依憲法增修條文「精簡化（虛級化）」，業務併入中央，已非地方自治團體。
```
